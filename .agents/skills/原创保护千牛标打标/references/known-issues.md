# 原创保护千牛标打标 — 已知问题速查

> 本文汇总 TTYCBH 千牛标打标过程中高频出现的拦截、格式错误与验证盲区。打标前优先核对本节，避免重复踩坑。

---

## 1. 准入拦截：「高原创能力要求」

**现象**

商家端入驻或点击「签约」时弹出：

> 抱歉，该服务现面向具备高原创能力要求的商家开放，如有需求您可联系店铺小二申请加入。

**根因**

`SellerEnterDomainServiceImpl.enter()` 调用千牛标读服务：

```java
qnTagReadFacade.hasUserDataTag(sellerId, "TTYCBH")
```

未打标时抛 `BizException` 拦截入驻。

**修复**

给目标 `seller_id` 打上原创保护商家准入千牛标 `TTYCBH`。

**代码位置**

`taobao-yc-serverless-domain/.../domain/service/impl/SellerEnterDomainServiceImpl.java:65-67`

**实现链路**

```text
QnTagReadFacadeImpl
  → QnResourceTagService.hasResourceTag(userId, qnTagCode, projectName)
  → 千牛平台侧标签服务
```

## 2. 后台上传 TXT 常见格式错误

千牛标管理后台上传 TXT 时，任何非纯数字行都会导致失败或部分失败。

| 错误场景 | 错误示例 | 正确做法 |
|---------|---------|---------|
| 文件格式非 TXT | `.xlsx`、`.csv` | 使用 `.txt` 纯文本文件 |
| Excel 导出科学计数法 | `2.21925E+12` | Excel 单元格设为「文本」后再复制到 TXT |
| 行尾空格 | `2213249110271 ` | 删除每行末尾空格 |
| 行尾逗号 | `2213249110271,` | 删除逗号，每行仅保留 sellerId |
| 中文备注 / 注释 | `2213249110271 // 测试账号` | 删除备注、注释、冒号等非数字内容 |

**正确格式示例**

```text
2213249110271
2219635657158
```

## 3. 打标成功后的二级校验

打标仅解决「入驻准入」问题，不代表后续流程一定通畅。常见二级校验：

| 现象 | 根因 | 处理 |
|------|------|------|
| 入驻后「可用权益数 = 0」，新建申请报错 `BIZ_ERROR::可用权益数不足` | 测试账号无剩余权益 | 充值权益 / 换有权益的测试号 / 小二端 cobweb 后台绕过（参考 `yc-quick-audit-data-create`） |
| 千牛标后台操作中途跳转登录 | 免登态过期 | 刷新登录态或重新登录后再操作 |

## 4. 验证清单

- [ ] 环境确认为预发 / 测试，未触碰生产卖家。
- [ ] 待打标 seller_id 属于测试白名单。
- [ ] 用户已二次确认打标列表。
- [ ] 生成的 TXT 每行均为纯数字 sellerId，无空格、逗号、中文备注。
- [ ] 打标后商家端不再提示「高原创能力要求」。
- [ ] 已调用 `SellerEnterToolService.enterSeller` 完成入驻。
- [ ] 若后续报错「可用权益数不足」，已切换到有权益的测试账号或走小二端绕过。
