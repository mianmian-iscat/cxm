# att-tf 管理

用户所有操作都通过当前 agent 完成；CLI 只是内部执行层，不让用户自己敲命令。

- 查询状态：内部执行 `att-tf status --json`，用自然语言解释授权平台、运行模式和接线漂移。
- 暂停/恢复：用户明确说暂停或恢复 att-tf 后，内部执行 `att-tf pause` 或 `att-tf resume`。
- 安装：用户已点名平台时直接使用这些平台；未点名时先展示当前检测到的受支持平台并询问选择，再内部执行一个带多个 `--platform` 的安装命令。
- 卸载：用户未点名平台时，先询问要卸载哪些当前已安装平台；始终展示目标平台及将删除的 att-tf Hook、受管理 Skill和OpenClaw注册，获得明确确认后才执行带 `--yes` 的卸载命令。仅在不允许交互且能可靠识别当前 agent 平台时传 `--caller-platform`；平台不支持或身份不可靠时拒绝。
- “卸载所有平台”不等于彻底卸载。只有用户明确要求彻底卸载并再次确认时才使用 `--purge`。

支持的平台只有：`claude`、`codex`、`openclaw`、`qoderwork`、`qoder`。

卸载最后一个平台前提醒：新会话会失去自然语言管理入口，但共享包、CLI和 `~/.att-tf` 数据默认保留。
