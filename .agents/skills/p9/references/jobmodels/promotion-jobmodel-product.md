# 产品岗 JobModel

## 通用能力 — 关键贡献及结果

聚焦拿结果的能力。

| 层级 | 要求 |
|------|------|
| FZ-P7 | 主导产品线，或重要产品，实现用户体验和产品数据有效提升 |
| FZ-P8 | 主导多产品线，或重要产品线，实现有效运营和增长 |
| FZ-P9 | 保证 BU 目标达成，为 BG 业务和公司中长期经营业绩带来显著影响；或通过为客户创造价值和创新，为所负责产品带来超越业界同类产品的影响力和商业结果；或通过洞见新的用户需求和赛道机会，凭借产品专业能力和商业模式定义独立将产品带到领先业界的影响力 |

## 专业能力 — 客户价值定义

能清晰定义客户价值和问题，提供优秀用户体验，完成产品设计。

| 层级 | 要求 |
|------|------|
| FZ-P7 | 清晰定义问题，对需求有深刻理解、判断和拆解，对技术的应用有较强认知，形成有创造性的方案 |
| FZ-P8 | 深度洞察商业和技术趋势，结合对业务规划的理解，形成相比业界大多数同类产品更高效和创新的全局规划和运营方案，在单个领域形成领先 |
| FZ-P9 | 具有成熟的系统架构和机制设计能力，形成跨领域的、业界领先的产品战略布局和全局规划，能实现规模化，产品情商（用户体验）优秀，跨领域复杂问题的定义能力优秀 |

## 专业能力 — 产品实现

能通过高效获取与整合资源将产品方案落地。

| 层级 | 要求 |
|------|------|
| FZ-P7 | 以影响力协同多团队，实现所主导产品线的规划落地并推进持续迭代 |
| FZ-P8 | 在 BU 层面具备影响力，使各利益方有机结合，实现所主导多产品线的全局规划落地并推进持续创新 |
| FZ-P9 | 在 BG 层面具备广泛影响力，通过配置资源，落地产品战略布局 |

## 通用能力 — 商业模式 & 商业节奏规划

具备对商业的敏锐和洞察力，并能在产品设计和实现中体现。

| 层级 | 要求 |
|------|------|
| FZ-P7 | 具备基本的成本 & 收益意识，从客户、合作方的角度思考产品价值和作出判断，保障产品的投入产出效益 |
| FZ-P8 | 理解产业，开展生态与竞合关系分析、判断，转化为产品承接，形成匹配商业节奏的产品节奏 |
| FZ-P9 | 预判产业和人群趋势，构建战略控制节奏，形成产品架构的前瞻布局 |
