# 个人成长方法论

> 本文件聚焦个人层面的成长方法论。团队层面的组织建设、授权、绩效等见 [organization-and-people](organization-and-people.md)。

## 26 项领导力素质

来自 P9-M4 领导力测评，按层次分组：

### 品格层（地基）
1. 在压力或诱惑下，坚持使命愿景，做正确的事情
2. 真实不装，言行一致，诚信正直
3. 谦虚自省，能保持持续学习，不断提升自己

### 共情层（连接）
4. 有爱商，能尊重包容，心中有他人
5. 利他，先人后己，乐于奉献，成就他人
6. 视人为人，愿意花时间去走近他人，了解他人
7. 对人的判断依据多视角多场景的信息，不仅仅凭主观感觉

### 格局层（方向）
8. 胸怀开放，能倾听，敢于突破自我，拥抱变化
9. 有眼光，看问题不停留在表面，能追本溯源
10. 能感知并把握未来趋势，可以识别机会和挑战
11. 既有战略目标和大图，又有实现路径和行动计划
12. 有足够的视野，能够判断创新的时机

### 影响层（带人）
13. 能在众人面前树立威信，让大家愿意追随
14. 有感召力和影响力，善于鼓舞士气，带给团队希望和动力
15. 知道团队需要什么样的人，能快速找到他们，凝聚成可信赖、共享共担的团队
16. 培养和发展人才梯队，持续提升组织能力

### 决断层（拿结果）
17. 敢于做决定，善于做取舍
18. 主动为创新争取资源和条件，并承担成本和结果
19. 有强大的决心，不等不靠，积极主动
20. 即使是剩下一个人，也能战斗到底 — be the last standing man
21. 不畏难，勇挑重担，专业执着，追求卓越
22. 遇到挫折和逆境能快速恢复，保持团队乐观向上和永不放弃

### 客户层（价值锚）
23. 以客户为行动的出发点，走近客户，了解客户，不断解决客户的困难
24. 不只 KPI 导向，理解客户价值，并以实现客户价值为目标

> 注意：第 17-22 项是"决心"的六种表达方式，它们共同构成一个判断标准：面对困难时的行为模式比顺境时的表现更能预测一个人的真实水平。

## 简历写作哲学

提炼自《前端开发工程师怎么写简历》。核心观点：简历不仅仅是履历，它的重要作用是展示能力。

### 七项原则

1. **始终署名** — email 标题、文件名、正文都要写明你是谁、应聘什么岗位、什么层级
2. **Word/PDF 格式** — 适配招聘系统，不给 HR 增加额外工作
3. **突出深度而非广度** — 高亮你最强的一个方向，引导面试官问你擅长的部分
4. **展示"作品"** — NPM 模块、组件 demo、架构图、Release 邮件、专利、带人案例。检验标准："展示的过程中两眼放光唾沫星子乱飞"
5. **描述结果而非任务** — 背景 → 你的做法 → 克服的困难 → 交付的结果 → 推广范围
6. **活跃的 GitHub 是强信号** — 绿色贡献图、维护良好的仓库、清晰的 README
7. **重点写：每次离职原因、可量化的结果、最好的项目详细写。忽略：证书、语言能力（除非流利）、不会的技术、个人简介**

## 面试方法论

### 六类面试问题设计

来自招聘方法论，六类问题覆盖不同维度：

1. **描述最具成就感的项目** — 真实做过的项目一定有总结，否则只是"一路做项目"
2. **有无带团队的经历** — 看如何分工、有无培训、代码冲突怎么解决、如何和后端协作
3. **需求变更如何应对** — 区分是"技能达不到推掉"还是"体验不佳推掉"，判断主动性
4. **拿某个页面估工期** — 经验丰富的人应对答如流，能说清风险和延期可能
5. **有没有推动过技术改革** — 看是结果导向还是为了技术而技术
6. **关注哪些新技术** — 看是不是真正喜欢技术，能否有互动交流

### 高潜力信号判断

四个职业阶段的特征：

- **前 2 年**：技能学习期，来啥活干啥活
- **2-3 年**：技能第一次瓶颈，开始注重沟通和职业技能
- **3+ 年**：突破"代码民工"瓶颈，有清晰职业方向
- **3-4+ 年**：持续技能突破，稳定，难招

关键信号："如果聊的 happy，是有缘分的。"但要区分自信和傲慢。

### 面试中的层级特征速查

| 层级 | 面试中的核心特征 |
|------|-----------------|
| P5 | 来了能干活，被安排的活独立跟下来 |
| P6 | 识别刚性需求，辩证执行，有数据意识 |
| P7 | 产品技术有主见，代码质量极高，能在脏乱差中逆袭，能动员人 |
| P8 | 预见方向，体系化思路，有自成一套的绩效方法论 |

## 招聘中的"潜力"判断

- **P5 的潜力定义**：在表达能力、职业技能、意识层面、专业技能中，有一两项达到 P6 要求
- **更重要的观察**：面试者是否还在快速成长期，能否 1-2 年内晋升至 P6
- **偏科严重的人直接锯掉**
- **意识不到自身瓶颈的人，也没有提升到 P6 的资本**

## 加速成长六要诀

蒸馏自 2017 年海豹营分享。不是教科书式的"如何成功"，而是从 2008-2017 十年职业经历中提炼的个人成长方法论。

### 职业叙事线（方法论的生长土壤）

六个要诀不是凭空想出来的，是从每一段真实经历中长出来的：

#### @2008 Yahoo — 技术的学院派

让人着迷的技术学院（文档、规范、技术创新），全球一流的技术储备，三流的产品。这一阶段的核心矛盾：**技术超前 vs 业务滞后，离"用户"太远**。精工细琢和快速试错的博弈——"科学严谨"的生产工艺 vs 快速的产品原型开发。

核心认知：
- **靠近大牛，模仿他们** — 雅虎全球代码仓库几乎全部开放，Rasmus Lerdorf、Doug Cutting、Douglas Crockford、Nicholas C. Zakas 等一批顶级工程师的代码都可以直接阅读学习。"通宵阅读大牛的代码，丝毫不觉得疲惫"，技术品味就是在这样的环境下塑造的
- **看似无产出的"充电"阶段，才是真正的积累** — 在雅虎既没有晋升也没有代表作品，只是情不自禁地靠近优秀的人、学习模仿他们。"顶着最底层的职级，花着最充裕的时间，一股蛮劲的学习，快乐且充实"
- **YUI3 的启示**："原来代码可以这样写"——把后端编程思想（模块化、依赖管理）应用在前端，在当时业界实属独创

#### @2010 淘宝 — 前端技术的荒漠

困惑和纠结：技术落后 vs 业务快速成长，技术成长 vs 业绩成长。选择"保持谦虚、寻找真相"，带着疑问对雅虎技术不断修正。**这一年的收获超过前两年的总和——真正的沉淀来自于输出、而非输入。**

核心认知：
- **代码即名片** — "任何一行我交付出去的代码都是我的作品，我不能轻慢"。保持良好编程习惯，代码署名即负责。代码片段在淘宝诸多仓库中被大量复用，最终被首席技术专家发现，促成负责淘宝首页项目的机遇
- **工作状态取决于技术能力** — "一个人的工作状态，完全取决于个人的技术能力，而和同事的水平、老板的眼界、合作方的专业度没有那么大关系"。代码结构合理、设计到位，根本不需要大量无畏的沟通和开会
- **因上努力，果上随缘** — "菩萨畏因，众生畏果。你送出去的每颗糖都去了该去的地方"。所有回报都不是求来的，发心正、努力实，美好的事情自然会发生

#### @2011-2012 — 学以致用

从 P（个人贡献者）到 M（管理者/协调者）的转变。关键认知：
- **协作能否成功由单方决定** — 不要等对方配合，自己先把规范和流程建起来
- **规范固化 vs 容忍混乱** — 管理者必须在这两者之间做选择

三个重要习惯养成：
1. **时间管理**：事预则立
2. **情绪管理**：全心投入
3. **内容管理**：要事第一

翻译四本技术著作（《JavaScript 权威指南》《编写可维护的 JavaScript》《JavaScript Web Applications》《JavaScript Patterns》）的体会：**写，是沉淀思考的最佳方式**。微不足道的坚持——积硅步至千里，足够的量变形成质变。

核心收获：
- **两项硬技能** — 翻译过程中意外习得：① **写长难句**（多介词逗号少句号，兼顾语义连贯），用于总结汇报；② **做脑图**（正交枚举所有关联概念，穷尽选项），用于信息归纳。"打腹稿能一气呵成，写纪要能一遍归档，做总结能言之成章——雪中送炭的神技能"
- **极客气质的感染** — 近距离接触 Zakas、Alex MacCaw、Stoyan 等作者后认识到：热爱编程和写作达到沉浸正念的状态，这种气质通过代码和文字透传出来。"只要初心纯粹，甘愿付出，落子无悔，纵使千里之外，也一样产生心灵的共鸣"

#### @2012 末 — 职业空窗期

晋升后工作驾轻就熟、感觉不到进步，"独孤求败的失落感像空窗期一样侵蚀工作热情"。

核心认知：
- **换工作解决不了内部失焦** — "换工作只是把这个状态延续到另一个环境，如果自己没有突破，还是会滑落到同样的糟糕状态"
- **职业瓶颈未必是能力瓶颈，很多时候是投入度瓶颈** — 必须靠自我突破重新找到投入点。最终选择读书和翻译作为突破口

#### @2013-2014 — 个人价值与向上管理

核心追问：谁在运行你的代码？谁在实践你的观点？谁在使用你的代码？什么人在因为你而获利？

向上管理方法论：让老板们"懂"你——给老板做密集知识灌输，争取 Boss 的认同，扫清工作障碍。KPI 的物理分解和化学分解（KPI 缓冲区）。

### 六个要诀

#### 要诀 1：坚持年度规划

每年给自己定一个关键词式目标：

- 2008：走出校园，找个注重技术的工作，并享受这份工作
- 2009：精通 YUI，吃透 Yahoo 前端技术
- 2010：在淘系的快节奏和压力下求生存
- 2011：做几个牛逼的项目压压惊
- 2012：搞定犀牛书
- 2013：斩断退路、重组团队
- 2014：带领航旅 FE 团队成为关键先生
- 2015：带出自信的团队、打造优雅高效的技术体系
- 2016：或许去赛马，或许去打磨一件属于自己的产品

规划不需要精确到 KR，但要有一个方向感。每年回顾时能看到自己在往前走。

#### 要诀 2：坚持开源

引用蒙台梭利："小家伙们不停的发现这个世界，深刻感受它的美，而且在这个过程中收获极大的乐趣……""小家伙们获得有条不紊的知识，这些知识激发了他们的热情，并让他们有分享的欲望……"

开源的驱动力：发现美 → 收获乐趣 → 有分享的欲望 → 输出倒逼输入。

#### 要诀 3：保持内心平静

- 不要被聒噪的表象影响心情
- **并行计划、串行做事** — 可以同时有多个方向的目标，但同一时间只做一件事
- 随时备忘、摆脱遗忘焦虑症 — 用工具（如 work 平台）把待办从脑子里清出去

#### 要诀 4：善用 KPI

- KPI 是**自我激励**非常棒的工具，不是应付考核的工具
- 框定目标，三省吾身 — 主动用 KPI 框定自己的方向，而非被动接受

#### 要诀 5：打破边界

- 时刻警惕单一技术工种带来的思维定势
- 摆脱约束、让行动更有力
- "不会开车的厨子不是好裁缝！" — 跨领域学习，不被岗位定义限制视野

#### 要诀 6：更犀利的做事

- **拒绝围观、直接参与** — 不做旁观者
- **不等授权、行动至上** — 不要等别人给你权力，先做起来
- **敢提要求、敢提需求** — 不自我设限
- **事必总结、规划长远** — 每件事做完都要沉淀，每个阶段都要看下一步

### 驱动力

六个要诀背后是三个驱动力：

1. **追求卓越的初心**
2. **热爱生活、乐于分享的心态**
3. **读懂过去、看破未来的欲望**

结论：**努力很重要，但"选择"更重要。**

## 团队文化建设精要

核心原则："让文化的归文化，让专业的归专业"

### 三个关键洞察

1. **"很多文化或价值观问题本质上是专业问题"** — 比如"长期主义"不是态度问题，是"能否分辨第一客户、刨除伪需求、澄清远期目标、设计长期规划"的专业能力问题
2. **"业绩是文化的基石，文化是达成业绩过程中的团队的肌肉记忆"**
3. **"TL 是团队的标签：你是什么样，你的团队就是什么样"**

### TL 精进的三个底层逻辑

1. **要打胜仗**：TL 总要带领团队拿下几个 3.75 分的项目
2. **个人价值**：TL 总要追求不断进步，并且让他人感到你的精进
3. **团队发展**：团队机遇（持续获得大项目）+ 小二成就（有人晋升有人成长）+ 团队标签（TA 们怎么看你，就怎么看待你的团队）

## 反模式

| 反模式 | 检测 | 修正 |
|--------|------|------|
| **简历=流水账** | 罗列做了什么，没有结果和作品 | 每个项目写"我做了什么→克服了什么→交付了什么→影响了什么" |
| **面试=背诵** | 回答标准化但没有个人思考 | 追问"为什么这么做"和"还有什么方案" |
| **成长=学更多** | 什么都学一点，什么都不深入 | 选 1-2 个维度深入突破，而非 6 个维度平均用力 |
| **文化=口号** | 把价值观贴在墙上但不落地 | 文化通过日常管理行为体现，不是通过标语 |
| **领导力=管人** | 认为领导力就是分配任务 | 领导力是在压力下做正确的事、成就他人、树立威信 |
| **规划=写纸上** | 年度规划写了就放抽屉里 | 每年一个关键词式目标，定期回顾修正 |
| **开源=刷存在感** | 开源只是为了宣传，没有真实积累 | 发现美 → 收获乐趣 → 输出倒逼输入 |
| **KPI=应付考核** | KPI 是老板给的任务清单 | 主动用 KPI 框定自己的方向，三省吾身 |
| **围观不参与** | 看到问题只评论不行动 | 不等授权、行动至上、直接参与 |
| **独孤求败=该跳槽了** | 工作驾轻就熟、感觉不到进步、绩效也不错但提不起劲 | 换工作解决不了内部失焦，靠读书/开源/深钻某个方向自我突破 |
| **代码=完成任务** | 写完能跑就行，注释文档能省则省 | "任何一行我交付出去的代码都是我的作品"——代码即名片，署名即负责 |
| **努力=求回报** | 付出就必须马上看到晋升加薪，否则躺平 | 菩萨畏因，众生畏果；因上努力，果上随缘 |
