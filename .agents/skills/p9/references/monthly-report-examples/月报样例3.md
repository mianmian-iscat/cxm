二）手淘 Tab 交付

1. 日常交付：10月主要是是支持双十一相关的需求，包括活动人力，氛围，会场的胶囊和首猜坑位改动频繁，均交付顺利。
2. 手淘 Tab 页改版：手淘Tab定在11月将行业金刚改小搜卡的形式，目前已经完成需求评审和行业对焦，本周进行技术评审和排期，主要压力来自行业需要重新通过Weex实现一套小搜卡同时保证包体积在控范围内，属于完全重构，研发成本较高，11月重点跟进这个需求。
3. 入淘 Tab 导购度假侧盖板：主要是行业首页的重新设计，完成产品侧评审，预期 11 月底发布，技术侧协作方式细节确认中。比较特殊的在于本次要按照 Weex 的规范写代码，同时需要严控包体积（度假行业压缩前 < 50kb）和视图的层级，所以只能从零开始重写代码，工作量比较大，存在一定人力风险。
4. 手淘舆情工单跟进：和测试安排了工单的流程化处理方式，第一优先级解决手淘端舆情工单的相关问题，10月份高优工单解决率100%。
