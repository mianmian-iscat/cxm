## 简评撰写指南

简评是评审报告中"做的好的"和"有待提升的"每个条目的核心单元。不是写评语，是写**有证据的判断**。

### "做的好的"写作公式

```
{角色定位 + 长期投入方向}，{具体项目/技术贡献}，{量化结果}。
{关联 JobModel}：{引用目标层级的具体要求}。
{价值判断}：{实属不易 / 非常难得 / 值得肯定 / 这一点尤为难得}。
```

**公式拆解**：

| 要素 | 作用 | 示例 |
|------|------|------|
| **角色定位** | 让读者知道 TA 是谁、在哪深耕 | "长期在酒店客户端团队持续打磨端体验" |
| **具体贡献** | 做了什么、解决了什么问题 | "主导设计沉淀了可复用的优化方案 performanceKit" |
| **量化结果** | 用数据证明价值 | "可交互时间降低至 0.7s 以内" |
| **JobModel 引用** | 证明符合目标层级要求 | "很好地符合 P7 对'主导端到端完整解决方案'的要求" |
| **价值判断** | 有温度的定性评价 | "拿到这样的成果很难得" |

**2-3 句话完成一条，不要超过 4 句。**

### "有待提升的"写作公式

```
{具体短板描述}。
{引用 JobModel}：从 P{目标层级} 对于"{具体要求}"的要求来看，有一定的提升空间。
{改进方向}：建议{具体可操作的建议}。
```

| 要素 | 作用 | 示例 |
|------|------|------|
| **短板描述** | 具体行为表现，不是性格评价 | "不要顾及分工和边界，更大胆直接犀利一些" |
| **JobModel 引用** | 证明差距有标准依据 | "从 P7 层级对于'主动协同上下游组织发起专项'的要求来看" |
| **改进方向** | 可操作的建议 | "建议更多的把业务中的技术实践借助架构师身份做进一步推广" |

**关键：不足必须指向行为和能力，不能指向性格。"太腼腆"要翻译成"在跨团队沟通中要敢于发起对话，不怕冲突"。**

### 简评类型学（候选人画像）

从 20 份真实评审中提炼出 6 种常见候选人画像，每种画像的"做的好的"侧重不同：

| 画像 | 典型特征 | "做的好的"侧重 | JobModel 锚点 |
|------|----------|---------------|--------------|
| **技术深耕型** | 长期在一个技术方向深耕，产出有深度 | 技术创新 + 性能数据 + 论文/专利 | "通过技术创新取得显著结果" |
| **平台架构型** | 搭建通用能力，影响多个业务域 | 组件沉淀 + 跨行业复用 + 研发效率 | "复用性技术方案带来增量收益" |
| **业务紧贴型** | 紧贴业务场景，客户口碑好 | 业务结果 + 客户反馈 + 数据看板 | "理解业务参与业务" |
| **PM 攻坚型** | 临危受命或从 0 到 1 交付 | 项目攻坚 + 跨团队协调 + 里程碑交付 | "协同各方发起专项并完成里程碑交付" |
| **稳定性守护者** | 幕后工作，保障系统稳定运行 | 架构治理 + 稳定性数据 + 腐化治理 | "所处环境、问题难度和交付复杂度" |
| **创新突破型** | 引入新技术/新方案，有前瞻性 | 新方案落地 + 行业对标 + 方法论沉淀 | "借鉴行业经验解决现有难题" |

### 常见改进方向模式

从真实评审中提炼出 5 类高频改进方向，几乎每个候选人至少命中一类：

| 改进方向 | 典型措辞 | JobModel 关联 |
|----------|----------|--------------|
| **视野/前瞻性** | "要更多和竞对比、和行业顶尖比"、"要有更高的目标设定" | "参与规划、主动发现技术支撑存在的瓶颈" |
| **跨团队协同** | "不要顾及分工和边界，更大胆直接犀利"、"敢于做交付承诺" | "主动协同上下游组织发起专项" |
| **业务理解** | "不能'交付即结束'"、"要更多的关注业务结果和数据" | "在理解业务的基础上参与规划" |
| **向上沟通/布道** | "多做分享和布道"、"善于总结提炼，做更多的向上沟通" | "技术突破在跨业务场景可被复用，产生技术影响力" |
| **ROI 意识** | "关键决策的业务价值需要量化"、"要有意识的控制体系建设的整体 ROI" | "考虑技术投产比 (ROI)" |

### 简评反模式

| 反模式 | 示例 | 修正 |
|--------|------|------|
| **空泛好评** | "工作认真负责，技术能力强" | 必须绑定具体项目和数据 |
| **性格评价** | "太内向"、"不够自信" | 翻译成行为："在跨团队沟通中要敢于发起对话" |
| **无 JobModel 引用** | "建议提升技术视野" | 必须引用 P{目标层级} 的具体要求 |
| **面面俱到** | 每条 5 句话以上 | 2-4 句完成，信息密度要高 |
| **千人一面** | 所有人的改进方向都是"提升沟通能力" | 根据候选人画像选择匹配的改进方向 |
| **只和自己比** | "相比去年有很大进步" | 要和竞对、行业标准比 |
