# AFD Brief 流程与版本管理

> Brief 是买手传递给产运的视觉生产需求，包含 5 大区块表单。

## Brief 生命周期

```
买手创建草稿 → DRAFT_BRIEF（仅买手可见）
    ↓ 提交
PENDING_BRIEF（产运可见）
    ↓ 确认              ↓ 驳回
IN_PRODUCTION      REJECTED_BRIEF
                        ↓ 买手重新编辑(fork新版本)
                   DRAFT_BRIEF (v2)
                        ↓ 重新提交
                   PENDING_BRIEF
```

## 版本管理规则

1. **首版无版本号** — 不展示版本区分
2. **驳回后fork** — 产运驳回后买手点击"重新编辑Brief"，系统fork新草稿
3. **版本侧栏** — fork后左侧出现 v1/v2 切换侧栏
4. **版本对比** — 可对比不同版本的内容差异
5. **版本递增** — 每次驳回+重编递增版本号（v1→v2→v3...）

## 5 大区块表单字段

### 1. 基础与风格
| 字段 | 类型 | 校验规则 |
|------|------|---------|
| 迭代名称 | 文本输入 | 必填，≤40字 |
| 风格定位 | 长文本 | 必填，20-200字 |

### 2. 目标人群
| 字段 | 类型 | 校验规则 |
|------|------|---------|
| 年龄 | 多选 | 必填 |
| 职业 | 多选 | 必填 |
| 其他职业说明 | 文本 | 条件必填（选了"其他"时），≤50字 |

### 3. 货盘与上新计划
| 字段 | 类型 | 校验规则 |
|------|------|---------|
| 品类占比 | 数值表格 | 必填，合计100% |
| 上新节奏 | 单选 | 必填 |
| 单次上新量 | 数字 | 必填 |

### 4. 视觉参考
| 字段 | 类型 | 校验规则 |
|------|------|---------|
| 对标店铺 | 对象列表 | ≥1家，每家需名称+链接 |
| 参考视觉图 | 图片上传 | 1-5张 |

### 5. 试拍准备
| 字段 | 类型 | 校验规则 |
|------|------|---------|
| 首次试拍商品 | item_id列表 | 最多10条 |

## 买手操作动线

1. 进入迭代详情 → Brief Tab
2. 填写 5 大区块表单
3. 点击"保存草稿"（DRAFT_BRIEF，仅自己可见）
4. 点击"提交产运确认" → 前端校验 → PENDING_BRIEF
5. （如被驳回）点击"重新编辑Brief" → fork v2 → 修改 → 重新提交

## 产运操作动线

1. 收到通知 → 进入迭代详情 → Brief Tab
2. 查看已提交的 Brief 内容
3. 选择操作：
   - **确认Brief** → IN_PRODUCTION（产运开始上传试拍）
   - **驳回Brief** → 弹窗：驳回原因（单选）+ 详细说明（必填≥10字）→ REJECTED_BRIEF

## 测试要点

### 正常流程
- 草稿保存后重新进入能恢复
- 提交后状态变为 PENDING_BRIEF
- 产运确认后状态变为 IN_PRODUCTION
- 产运驳回后状态变为 REJECTED_BRIEF

### 边界场景
- 风格定位恰好 20 字 / 19 字（边界）
- 品类占比合计 99% / 101%（校验失败）
- 对标店铺 0 家（校验失败）
- 参考视觉图 6 张（超出上限）

### 版本管理
- 首版不显示版本号
- 驳回后出现"重新编辑Brief"按钮
- fork 后出现 v1/v2 侧栏
- 可切换版本对比内容
