# AFD 角色权限矩阵

> 5 类角色在不同页面和状态下的操作可见性。

## 角色定义

| 角色 | 标识 | 说明 |
|------|------|------|
| buyer（买手） | 店铺关系角色 | 负责店铺的视觉迭代发起人 |
| operator（产运） | 角色组权限 | 负责 Brief 确认和试拍上传 |
| leader（Leader） | 角色组权限 | 负责复核买手审核结论 |
| admin（管理员） | 跨店铺管理 | 全部操作权限，可代操作 |
| viewer（其他人） | 只读 | 仅查看有权限范围的信息 |

> **关键规则**：买手是相对店铺的关系角色。同一个人在非负责店铺下按"其他人"处理。

## 按钮三态控制

| 状态 | 含义 | 测试验证 |
|------|------|---------|
| enabled | 可见+可点击 | 按钮存在且可交互 |
| disabled | 可见+不可点击 | 按钮存在但灰色 |
| hidden | 不可见 | 按钮不存在于DOM中 |

## 测试要点

1. 每个角色在每种状态下验证所有操作的可见性
2. 买手角色：负责店铺 vs 非负责店铺的权限差异
3. admin 代操作不跳过流程校验（如必填字段仍需填写）
4. viewer 在任何状态下都只能只读查看
5. 终态（ARCHIVED/CANCELLED）下所有操作按钮隐藏
6. 按钮三态切换正确（enabled/disabled/hidden）
