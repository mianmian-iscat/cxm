# AFD 试拍上传与评审流程

> 试拍评审是围绕图组的上传/审核/复核/补拍闭环。

## 试拍上传动线（产运）

1. 进入迭代详情 → 试拍与评审 Tab
2. 默认展示 5 个上传坑位
3. 每个坑位上传一组图组（见下方图组结构）
4. 可点击"增加坑位"扩展（最多 10 组）
5. 或使用"Excel 批量导入"
6. 点击"保存草稿"或"发起评审"
7. 发起评审前触发最小集校验

## 图组结构

| 图片类型 | 数量要求 | 说明 |
|---------|---------|------|
| 原款图 | 1 张 | 商品原款照片 |
| 视觉模板图 | ≥1 张 | 参考视觉模板 |
| 首图 | 1 张 | 展示用首图 |
| 套图 | ≥5 张 | 多角度/多姿势图组 |
| 标签 | ≥3 种 | 构图/姿势/角度各至少1种 |

## Excel 批量导入

| 列名 | 必填 | 说明 |
|------|------|------|
| 组编号 | ✅ | 图组序号 |
| Item ID | ✅ | 商品ID |
| 图片类型 | ✅ | 原款图/模板图/首图/套图 |
| 图片URL | ✅ | 图片地址 |
| 构图 | 选填 | 构图标签 |
| 姿势 | 选填 | 姿势标签 |
| 角度 | 选填 | 角度标签 |

Excel 包含两个 Sheet：
- **试拍图数据**：图片明细
- **字段可选值**：枚举参考

## 最小集校验规则

1. **组数**：≥5 组达标
2. **每组图片**：原款图1张 + 模板图≥1张 + 首图1张 + 套图≥5张
3. **标签种类**：构图/姿势/角度 各 ≥3 种（跨所有组统计）
4. **前端+后端双重校验**：前端预览提示，后端最终校验

## 买手审核动线

1. 收到评审通知 → 进入迭代详情
2. 状态 = IN_REVIEW → 试拍与评审 Tab
3. 进入审核视图（大图模式）
4. 左侧图组导航，逐组查看
5. 对每张图：通过 / 弃用（选择弃用原因）
6. 弃用原因：穿搭穿法 / 模特长相 / AI感强 / 其他
7. 支持撤销弃用
8. 支持键盘左右切换图片
9. 全部审核后提交结论

### 买手判定规则

| 规则 | 条件 | 结果 |
|------|------|------|
| 单组通过 | 该组可用图片 ≥5 张 | 组通过 |
| 迭代通过 | 通过的组数 ≥3 组 | 买手结论 = 通过 |
| 迭代驳回 | 通过的组数 <3 组 | 买手结论 = 驳回 |

### 判定示例

- **场景1**：8组上传，5组通过(每组可用≥5张)，3组不通过 → 买手结论=通过
- **场景2**：6组上传，2组通过，4组不通过 → 买手结论=驳回
- **场景3**：5组上传，3组通过，2组不通过 → 买手结论=通过

## 结果视图

- 角色：Leader / 产运 / 查看者
- 展示：铺开中小图，通过图片在上，弃用清单在下
- 批次标识：新批次在上，历史批次在下
- 只读模式

## Leader 复核动线

1. 状态 = PENDING_LEADER → 进入试拍与评审 Tab
2. 默认展示结果视图（只读）
3. 查看买手审核结论和详细标注
4. 三选一决策：
   - **买手结论=通过时**：确认通过(→归档) / 打回买手(填写调整意见10-500字)
   - **买手结论=驳回时**：确认驳回(→补拍) / 打回买手

## 打回/补拍流程

- **Leader 打回买手**：RETURNED_TO_BUYER → 买手重新调整标注 → PENDING_LEADER
- **Leader 确认驳回**：RETURNED → 产运查看结果视图 → 补充上传(追加v2/v3) → IN_REVIEW
- **合并图池规则**：补拍后买手以 v1+v2+... 合并图池计算通过指标

## 测试要点

1. 验证最小集校验的边界（恰好5组/4组）
2. 验证 Excel 导入的行级/组级错误提示
3. 验证买手判定规则的场景计算
4. 验证弃用/撤销弃用的状态切换
5. 验证补拍后合并图池的指标重算
6. 验证 Leader 三选一决策的状态转换
