- **AFD 与 F88 共用域名** `pre-aifashion-xiaoer.alibaba-inc.com`，通过 `X-AFD-Emp-Identity` 租户头切换

## 四、审核操作详情

### 4.1 审核类型

| 类型 | qt值 | 组件 | 说明 |
|------|------|------|------|
| 单图审核 | qt=1 | SingleImageReview | 单张商品主图 |
| 套图审核 | qt=2 | SetImageReview | 多张商品图(passedImg1~5) |
| 封面图审核 | qt=4 | CoverImageReview | 封面图，驳回可触发重生 |

### 4.2 审核状态流转

```
待分配 → 待审核 → 审核通过 / 审核驳回 / 已撤回 → 已完成
              ↓ (qt=4驳回)
         触发重生(reGen) → 重生完成 → 重新审核
```

### 4.3 编辑操作后数据字段变化

| 字段 | 操作前 | 确认后 |
|------|-------|-------|
| `material.url` | 原图URL | 新图URL（由localAdjustUrl写入） |
| `material.originUrl` | 原始URL（不变） | 原始URL（不变） |
| `material.localAdjustUrl` | 编辑后URL | 清空或保留 |
| `material.localAdjustStatus` | ≠0 | =0 |

**前端逻辑**：`handleCopyUrl(img.originUrl || img.url)` — originUrl 优先

### 4.4 下游数据流转

```
审核确认 → output_json.passedImg → g_workflow_instance.common_variable → 下游节点input_data
```

下游节点类型：算法过滤、套图生产、素材生产

## 五、质量度量体系

### 审核任务指标
- **审核通过率** = 通过数 / 总审核数 × 100%
- **平均审核耗时** = Σ(完成时间 - 开始时间) / 审核总数

### 抽检任务指标
- **抽检一致率** = 与原审核一致数 / 抽检总数 × 100%
- **误通过率** = 应驳回但通过数 / 抽检总数 × 100%
- **误驳回率** = 应通过但驳回数 / 抽检总数 × 100%

### 埋雷任务指标
- **埋雷准确率** = 正确判定数 / 埋雷总数 × 100%（核心KPI）
- **误放率** = 错误通过违规埋雷 / 违规总数（要求 < 5%）

### 6.5 典型策略链路搭配模式（生产环境实证）

**5环节标准流水线**（来源：完整主图链路_082665、zy测试主图生成链路）：

```
刷标签 → 首图生图 → 首图审核 → 套图生图 → 套图审核
```

**各环节策略内部节点编排**：

| 环节 | 策略名示例 | 节点编排 | 入参 | 出参 |
|------|-----------|---------|------|------|
| 刷标签 | 入参图刷标签 | 季节标签 | seller_id, seed_image_url, tao_cate | season_tag, style_tag, industry_tag |
| 首图生图 | 首图生图策略1~4 | LLM文本生成 → 模板匹配 → 生图 | +item_id, style_tag, season_tag | main_img_url, template_image_url |
| 首图审核 | 首图审核 | 人工审核 | +image1, image2, remark | out_image1, out_image2, no_pass_reason |
| 套图生图 | 套图生图策略 | 生图/Map生图 | +main_img_url | set_img_url |
| 套图审核 | 套图审核 | 人工审核 | +set_img_url | no_pass_reason |

**关键搭配规律**：
- 生图之后**必有**人工审核（人工审核节点）
- LLM文本生成 → 模板匹配 → 生图 是生图策略经典三段式
- 入参在链路中逐级传递：seller_id → seed_image_url → main_img_url → set_img_url
- 上游出参 = 下游入参（首图生图出参 main_img_url → 首图审核入参 image1）

**节点保存API限制**：
- 季节标签/Caption 等节点的 imgUrl/taoCate 需配置 dataSourceConfig，否则 save API 返回 `B9999` 错误
- LLM文本生成、人工审核 节点可正常保存（无需额外数据源配置）
