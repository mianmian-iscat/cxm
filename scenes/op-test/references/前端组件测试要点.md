### 🚨 实战经验：Select 下拉鲁棒性方案

**问题**：原创保护小二端筛选区域含多个 Select（申请状态7项、专利权状态21项），`evaluate().click()` 展开无效。

**原因**：Ant Design Select 下拉菜单挂载在 `document.body` 末尾，不在当前组件 DOM 内。

**完整方案**：
```javascript
// Step 1: 展开 Select
async function openSelect(page, selectSelector) {
  const arrow = await page.$(selectSelector + ' .ant-select-arrow');
  if (arrow) {
    await arrow.click();
  } else {
    const box = await page.$(selectSelector).then(el => el.boundingBox());
    await page.mouse.click(box.x + box.width - 10, box.y + box.height / 2);
  }
  await new Promise(r => setTimeout(r, 300));
}

// Step 2: 确认展开
async function verifyDropdownOpen(page) {
  return await page.evaluate(() => {
    const dd = document.querySelector('.ant-select-dropdown:not(.ant-select-dropdown-hidden)');
    return dd !== null;
  });
}

// Step 3: 选择目标项
async function selectOption(page, optionText) {
  await page.evaluate((text) => {
    const options = document.querySelectorAll('.ant-select-item-option-content');
    for (const opt of options) {
      if (opt.textContent.trim().includes(text)) {
        opt.closest('.ant-select-item').click();
        return;
      }
    }
  }, optionText);
}
```

**关键教训**：puppeteer-core 不支持 `$x`（XPath），改用 `document.querySelectorAll` + `evaluate` 实现元素查找。

### 🚨 实战经验：Modal 弹窗确认按钮多文案

**问题**：不同弹窗确认按钮文案不一致（"确定"/"确认"/"创建"/"提交"/"绑定"），且部分按钮文本含空格（如"确 定"）。

```javascript
async function clickModalConfirm(page) {
  const confirmTexts = [/确.*定/, /确.*认/, /创建/, /提交/, /绑.*定/];
  await page.evaluate((patterns) => {
    const buttons = document.querySelectorAll('.ant-modal .ant-btn-primary');
    for (const btn of buttons) {
      const text = btn.textContent.replace(/\s/g, '');
      if (patterns.some(p => new RegExp(p).test(text))) {
        btn.click();
        return;
      }
    }
    if (buttons.length > 0) buttons[buttons.length - 1].click();
  }, confirmTexts.map(r => r.source));
}
```

### 🚨 实战经验：`waitForTimeout` 已废弃

**问题**：puppeteer-core v22+ 已废弃 `page.waitForTimeout()`，调用报错 `page.waitForTimeout is not a function`。

**替代方案**：
```javascript
// ❌ 旧写法（会报错）
await page.waitForTimeout(500);

// ✅ 新写法
await new Promise(r => setTimeout(r, 500));
```

### 等待策略（修正版）

```javascript
// 等待组件出现
await page.waitForSelector('.ant-modal', { timeout: 10000 });

// 等待 MTOP 网络请求完成（原创保护核心等待模式）
await page.waitForResponse(res => res.url().includes('mtop'), { timeout: 15000 });

// 等待动画完成（正确写法）
await new Promise(r => setTimeout(r, 500));

// 等待多个条件同时满足
await Promise.all([
  page.waitForSelector('.ant-table-tbody tr'),
  page.waitForResponse(res => res.url().includes('taobao.industry.yc'))
]);
```

## MTOP 请求等待与数据构造（实战经验）

### 为什么必须等待 MTOP

原创保护平台（商家端/小二端）所有数据交互均走 MTOP 协议。不等待 MTOP 响应直接操作 DOM 会导致：
- 列表为空（数据未加载完）
- 按钮状态不正确（条件渲染依赖接口返回）
- 提交失败（表单数据依赖前置接口）

### MTOP 请求拦截模式

```javascript
// 捕获特定 MTOP 响应
const response = await page.waitForResponse(
  res => res.url().includes('taobao.industry.yc.right.page.query') && res.status() === 200,
  { timeout: 15000 }
);
const data = await response.json();
```

### 浏览器内直接调用 MTOP（测试数据构造）

原创保护测试数据**一律走接口**，不走 UI 手动操作：

```javascript
// 商家端（千牛环境）调用 MTOP
await page.evaluate(async () => {
  const result = await window.lib.mtop.request({
    api: 'taobao.industry.yc.seller.sign',
    v: '1.0',
    data: { sellerId: '2213249110271' }
  });
  return result;
});
```

**⚠️ 重要**：MTOP Cookie 是 httpOnly，无法在非浏览器环境调用，必须在已登录的浏览器页面内 `evaluate` 执行。

## 登录与认证（实战经验）

### SSO 登录无法自动化的问题

原创保护两端均需 SSO 登录：
- 商家端：千牛 SSO → 淘宝 cookie
- 小二端：BUC SSO → 阿里内网 cookie

首次登录会触发 MFA/可信设备认证，自动化脚本无法处理。

### 解法：CDP 调试端口复用登录态

```bash
# 必须先关闭所有 Chrome 窗口，再执行：
/Applications/Google\ Chrome.app/Contents/MacOS/Google\ Chrome \
  --remote-debugging-port=9222 \
  --user-data-dir=/tmp/chrome-debug
```

```javascript
// puppeteer-core 连接已登录的 Chrome
const browser = await puppeteer.connect({
  browserURL: 'http://localhost:9222'
});
const pages = await browser.pages();
const page = pages[0]; // 复用已登录页面
```

**注意**：启动后需等待数秒再连接，否则 fetch CDP 会失败。

## 维权按钮条件渲染（实战经验）

### 按钮显示逻辑（需求#83837371）

"发起维权" 按钮需同时满足：
1. `yc_right.status` = `YC_PROTECTING`（保护中）
2. 商品确认一致性（`itemAuditStatus` 通过）
3. 保护到期日前 20 天内（`protect_expire_time` 计算 `days_left ≤ 20`）

### 自动化验证方式

```javascript
// 检查按钮是否渲染
async function checkRightButton(page) {
  const btn = await page.$('button:has-text("发起维权"), [class*="right-btn"]');
  if (!btn) return { rendered: false };
  
  // 必须检查可见性（DOM存在≠可交互）
  return await page.evaluate((el) => {
    const rect = el.getBoundingClientRect();
    const style = window.getComputedStyle(el);
    return {
      rendered: true,
      visible: rect.width > 0 && rect.height > 0,
      disabled: el.disabled || style.pointerEvents === 'none',
      display: style.display
    };
  }, btn);
}
```

## 阻塞处理策略（Qoder 实战总结）

执行 UI 用例时遇到阻塞应遵循三层递进策略：

| 层级 | 操作 | 说明 |
|------|------|------|
| 第一层 | 知识库优先 | 穷尽知识库/SKILL.md/历史记忆查找方案 |
| 第二层 | 技术替代 | UI不可操作时改用 MTOP API 或 CDP 直调 |
| 第三层 | 精确跳过 | 记录阻塞原因+截图后跳过，继续后续用例 |

**典型应用**：
- 签约流程 UI 依赖外部服务 → 改用 `taobao.industry.yc.seller.sign` API 直调
- 快审图片上传 OSS 超时 → CDP `DOM.setFileInputFiles` + 等待上传回调
- 支付链接无法自动化 → 半自动方式（UI建单 + API取支付链接）
