# 搭配创建/编辑操作

搭配创建和编辑的详细操作流程已包含在 [material-mgmt.md](material-mgmt.md) 的区域三章节中：

- **编辑搭配** → 区域三 · 交互操作 · 第 3 节
- **创建图文搭配** → 区域三 · 交互操作 · 第 4 节（含完整 4 步流程）
- **文件上传** → 编辑搭配章节内的"文件上传操作"（7 步流程）
- **删除搭配** → 区域三 · 交互操作 · 第 5 节

## 快速索引

| 操作 | 关键步骤 | 注意事项 |
|------|---------|---------|
| 上传图片 | 清遮挡 → 点上传 → iframe → 本地上传 → 选图 → 裁剪 → 确定 | 裁剪必须，checkbox 需 hover |
| 添加商品 | 锚点弹窗 → 添加商品 → 切"按商品ID" → 搜索 → 勾选 → 确认 | 搜索框用 setter 不用 type() |
| 填写文案 | textarea#title + textarea#description | React setter 写入 |
| 保存/发布 | 保存草稿（安全）/ 发布内容（上线） | 保存后自动跳回列表 |
