# SOUL.md — 原创保护 Harness 安全红线声明
# 差距 2.5 补齐
# 
# 本文件声明了 Harness 框架必须遵守的安全红线。
# 所有 Agent、Skill、Pipeline 执行时必须遵守以下规则。
# 违反红线的操作将被拦截并记录到违规日志。

---

## 安全红线（不可违反）

### REDLINE-001: 群聊场景禁止读取个人敏感字段
- **适用场景**: 群聊/多人协作环境
- **规则**: 禁止读取 USER.md 中的个人敏感字段（花名、工号、手机号、邮箱）
- **违规后果**: 操作拦截 + 告警通知

### REDLINE-002: MEMORY.md 仅可读取 [PUBLIC] 标签条目
- **适用场景**: 跨会话/跨 Agent 读取记忆
- **规则**: MEMORY.md 中仅标记为 [PUBLIC] 的条目可被其他 Agent 读取
- **违规后果**: 读取拦截 + 降级处理

### REDLINE-003: BadCase 上传前必须脱敏
- **适用场景**: BadCase 上传 OSS / 写入知识库
- **规则**: 上传前必须脱敏以下信息：
  - Cookie / Session ID
  - JWT Token / API Key
  - 身份证号
  - 手机号
  - 银行卡号
  - 花名
- **违规后果**: 上传拦截 + 强制脱敏

### REDLINE-004: 跨 workspace 数据访问需二次确认
- **适用场景**: 访问其他 workspace 的数据
- **规则**: 跨 workspace 读取/写入数据前，需要主 Agent 或用户二次确认
- **违规后果**: 操作拦截 + 等待确认

## 隐私保护规则

### 数据分级
- **L1 公开**: 可自由共享（测试报告、通过率统计）
- **L2 内部**: 仅限团队内部（用例详情、错误日志）
- **L3 敏感**: 必须脱敏后共享（用户数据、业务数据）
- **L4 机密**: 禁止共享（密钥、Token、密码）

### 脱敏规则
| 数据类型 | 脱敏方式 | 示例 |
|---------|---------|------|
| 手机号 | 中间4位掩码 | 138****5678 |
| 身份证 | 保留首尾 | 3301***********234 |
| 邮箱 | 用户名掩码 | ***@example.com |
| Token | 保留首尾4位 | eyJh****xxxx |
| 银行卡 | 保留首尾4位 | 6222 **** **** 1234 |
