## 🎯 规则匹配 × 模板包

### 字段清单

| 序号 | 字段名 | 必填性 | 类型 | 默认值 | 说明 |
|-----|--------|-------|------|--------|------|
| 1 | 匹配模式 | ✅ 必填 | select | - | 选择"规则匹配" |
| 2 | 数据来源 | ✅ 必填 | select | - | 选择"模板包" |
| 3 | 应用环节 | ✅ 必填 | select | - | 搭配/视觉/套图 |
| 4 | 应用场景 | ✅ 必填 | select | - | 主图素材/种草素材 |
| 5 | **seller_id** | ✅ **强制必填** | - | - | **Start节点必须配置** |
| 6 | 排序维度 | ⚠️ 可选 | list | - | 类目粗分类、季节 |
| 7 | 硬匹配字段 | ⚠️ 可选 | select | - | seller_id 等 |
| 8 | 目标匹配数量 | ✅ 必填 | input | 4 | 数字 |
| 9 | 疲劳度 | ⚠️ 可选 | input | - | 数字 |

### 校验规则

#### ✅ 必填字段校验

1. **seller_id 强制校验**
   ```
   规则：模板包模式下 seller_id 为强制字段
   错误提示："该策略中包括模板匹配，但策略入参中没有商家ID"
   解决方案：配置 Start 节点 → 新增字段 → 选择 seller_id
   ```

2. **应用环节必填**
   ```
   规则：必须选择应用环节（搭配/视觉/套图）
   作用：决定模板包的筛选条件
   ```

3. **应用场景必填**
   ```
   规则：必须选择应用场景（主图素材/种草素材）
   作用：决定模板包的筛选条件
   ```

#### ⚠️ 可选字段校验

1. **排序维度可选**
   ```
   规则：类目粗分类和季节为可选字段
   默认行为：不选时应使用默认逻辑
   DOM结构：ant-list-item，非 ant-select
   ```

2. **硬匹配字段可选**
   ```
   规则：seller_id 等硬匹配字段为可选
   作用：强制匹配指定字段
   ```

#### 🔄 取数逻辑

```
【搭配 × 主图素材】→ 模板包【搭配 × 主图素材】全部使用中状态
【视觉 × 主图素材】→ 模板包【视觉 × 主图素材】全部使用中状态
【套图 × 主图素材】→ 模板包【套图 × 主图素材】全部使用中状态
```

## 🎓 常见错误与解决方案

### 错误 1：Start节点未配置seller_id（规则匹配×模板包）

```
错误提示："该策略中包括模板匹配，但策略入参中没有商家ID"
原因：模板包模式下 seller_id 为强制字段
解决方案：
  1. 点击 Start 节点
  2. 点击"新增字段"
  3. 选择 seller_id
  4. 保存节点
```

### 错误 2：入参未配置数据来源

```
错误提示："节点模板匹配的入参 styleImageUrl 数据来源配置异常:未知数据来源: null"
原因：入参未配置数据来源
解决方案：
  1. 编辑模板匹配节点
  2. 配置入参区域的数据来源（styleImageUrl → 模板库/模板包）
  3. 配置入参区域的数据来源（caption → 上游节点）
  4. 保存节点
```

### 错误 3：模型匹配配置了排序维度

```
问题：模型匹配模式没有"排序维度"字段
原因：模型匹配使用AI算法，不需要手动配置排序
解决方案：
  1. 如果需要手动配置排序，请改用"规则匹配"模式
  2. 如果使用"模型匹配"模式，请依赖AI算法自动排序
```

### 错误 4：规则匹配配置了模型选择

```
问题：规则匹配模式没有"模型选择"字段
原因：规则匹配使用固定规则，不需要AI模型
解决方案：
  1. 如果需要AI模型匹配，请改用"模型匹配"模式
  2. 如果使用"规则匹配"模式，请使用固定规则配置
```

## 🔧 DOM 定位注意事项

### 1. 排序维度使用 ant-list-item 结构

```javascript
// ❌ 错误：排序维度不是 ant-select
const select = item.querySelector('.ant-select');

// ✅ 正确：排序维度是 ant-list-item
const listItems = drawer.querySelectorAll('.ant-list-item');
for (const item of listItems) {
  if (item.textContent.includes('类目')) {
    item.click();
  }
}
```

### 2. 模型选择字段仅在模型匹配模式下存在

```javascript
// 先选择匹配模式
const modeSelect = ...; // 选择"模型匹配"

// 等待联动字段渲染
await page.waitForTimeout(1500);

// 再定位模型选择字段
const modelSelect = drawer.querySelector('.ant-form-item:has(label:has-text("模型选择"))');
```

### 3. 硬匹配字段仅在规则匹配模式下存在

```javascript
// 先选择匹配模式
const modeSelect = ...; // 选择"规则匹配"

// 等待联动字段渲染
await page.waitForTimeout(1500);

// 再定位硬匹配字段
const hardMatchField = drawer.querySelector('.ant-form-item:has(label:has-text("硬匹配字段"))');
```
