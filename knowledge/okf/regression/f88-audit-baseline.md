# F88 审核回归基线

## P0 用例（必须通过）

| ID | 用例名称 | 验证点 |
|----|---------|--------|
| TC01 | 审核任务列表加载 | 页面正常渲染、列表数据展示 |
| TC02 | 审核通过操作 | 状态变为"审核通过"、DB 状态更新 |
| TC03 | 审核驳回操作 | 驳回弹窗、必填校验、状态变更 |
| TC04 | 审核转交操作 | 转交弹窗、人员选择、任务转移 |
| TC05 | 查看大图 | Modal 弹出、图片加载 |
| TC06 | 下载原图 | 下载触发、文件保存 |

## P1 用例（建议通过）

| ID | 用例名称 | 验证点 |
|----|---------|--------|
| TC07 | 批量审核 | 多选、批量通过/驳回 |
| TC08 | 审核标准管理 | 标准列表、编辑、保存 |
| TC09 | 任务管理 | 任务列表、筛选、撤回 |
| TC10 | 重生图流程 | 触发重生图、状态流转 |

## 回归执行频率

- P0: 每次发版前必跑
- P1: 每周至少一次
