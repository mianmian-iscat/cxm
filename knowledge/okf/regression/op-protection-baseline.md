# OP 维权回归基线

## P0 用例（必须通过）

| ID | 用例名称 | 验证点 |
|----|---------|--------|
| TC01 | 商家签约入驻 | 签约状态变更、DB 记录 |
| TC02 | 权利申请提交 | 状态流转、DB 记录 |
| TC03 | 结算金额计算 | 公式正确性、精度容差 |
| TC04 | 维权线索提交 | 线索创建、状态变更 |
| TC05 | 首发标签编辑权限 | 9 类白名单 + T+3 校验 |

## P1 用例（建议通过）

| ID | 用例名称 | 验证点 |
|----|---------|--------|
| TC06 | 转普通申请 | 状态流转、触发条件 |
| TC07 | 补贴触发 | 时序规则、金额正确 |
| TC08 | 保护期到期 | 180 天±1 天容差 |
| TC09 | 禁发期行为 | 发布灰态、维权禁用 |
| TC10 | 退款计算 | remaining_count × 500 |

## 回归执行频率

- P0: 每次发版前必跑
- P1: 每周至少一次
