# 数据安全红线

## 铁律：禁止删除历史存量数据

- **规则**: 任何测试脚本、自动化流程都**禁止**删除历史存量数据
- **范围**: F88 策略/审核任务、OP 权利/结算记录、AFD 迭代数据
- **原因**: 历史数据可能被其他团队引用，删除不可恢复
- **正确做法**: 只创建新数据用于测试，测试完成后标记为测试数据（不删除）

## 租户隔离

- **规则**: F88 和 AFD 数据通过 `X-AFD-Emp-Identity` 头隔离
- **陷阱**: 切换租户后，前一个租户的数据不可见（不是删除，是隔离）
- **验证**: 操作前确认当前租户身份

## 测试数据命名规范

- 测试数据名称/标题包含 `[TEST]` 或 `[自动化]` 前缀
- 便于识别和清理（但不主动删除）

## 造数安全

- 造数 API 只创建不删除
- 如果必须清理，只清理本次会话创建的数据（通过创建时间戳识别）
- 禁止使用 `DELETE FROM` 直接操作生产数据库
