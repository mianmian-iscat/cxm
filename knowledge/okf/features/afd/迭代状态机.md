# AFD 迭代状态机

## 10 状态流转

```
草稿 → 待提交 → Brief 制作中 → Brief 完成
  → 试拍中 → 试拍完成 → 买手审核中
  → 买手审核通过 → Leader 复核中 → 已归档
                                  → 终止迭代
```

## 状态说明

| 状态 | 含义 |
|------|------|
| 草稿 | 新建迭代，未提交 |
| 待提交 | 信息填写完成 |
| Brief 制作中 | 视觉企划制作中 |
| Brief 完成 | 企划完成，等待试拍 |
| 试拍中 | 试拍上传中 |
| 试拍完成 | 试拍图已上传 |
| 买手审核中 | 买手逐组审核大图 |
| 买手审核通过 | 买手通过 |
| Leader 复核中 | Leader 最终复核 |
| 已归档 | 归档完成，生成基准包 |

## 角色权限矩阵（5 类角色）

| 角色 | 可操作 |
|------|--------|
| 买手 | 创建迭代、上传试拍、审核 |
| Leader | 复核、归档、终止 |
| 运营 | 全流程管理 |
| 商家 | 查看、上传试拍 |
| 系统 | 自动流转、超时处理 |
