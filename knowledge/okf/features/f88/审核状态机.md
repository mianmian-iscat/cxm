# F88 审核状态机

## 状态枚举

| 状态 | 含义 | 可流转到 |
|------|------|---------|
| 待审核 | 任务已分配，等待审核员处理 | 审核通过、审核驳回、已撤回 |
| 审核通过 | 素材符合审核标准 | — (终态) |
| 审核驳回 | 素材不符合标准，需重新生产 | — (终态，可重新生成任务) |
| 已撤回 | 任务被管理员撤回 | — (终态) |

## 素材类型

| 类型 | 说明 | 审核节点 |
|------|------|---------|
| 主图 | 商品主图 | 图片审核节点 |
| 详情页 | 商品详情页长图 | 图片审核节点 |
| 白底图 | 白底商品图 | 图片审核节点 |
| 场景图 | 场景化展示图 | 图片审核节点 |
| 标题 | 商品标题文本 | 文本审核节点 |
| 描述 | 商品描述文本 | 文本审核节点 |

## 页面入口

- **个人任务中心**: `https://pre-aifashion-xiaoer.alibaba-inc.com/review/personal-task-center`
- **审核标准管理**: `https://pre-aifashion-xiaoer.alibaba-inc.com/review/audit-standard`
- **任务管理**: `https://pre-aifashion-xiaoer.alibaba-inc.com/review/task-management`

## 租户身份

通过 `X-AFD-Emp-Identity` 请求头切换 AFD/F88 身份。审核任务按租户隔离。

## 边界条件

1. 审核通过后不可撤回（需管理员权限）
2. 驳回时必须填写驳回原因（按钮 disabled 直到填写）
3. 同一任务不可重复审核（幂等校验）
