# OP 签约入驻规则

## 签约类型

| 类型 | 条件 | 入口 |
|------|------|------|
| 9 类商家签约 | 类目在白名单内 | 千牛端 / 小二端 |
| 非 9 类签约 | 类目不在白名单 | 仅小二端 |
| 童装童鞋签约 | 特殊类目 | 千牛端 |

## 9 类白名单类目 ID

`16, 30, 50006843, 50011740, 1625, 50010404, 50006842, 28, 50468001`

## 千牛标准入

- 商家必须拥有 **TTYCBH 千牛标** 才能进入原创保护服务
- 无标商家看到提示："抱歉，该服务现面向具备高原创能力要求的商家开放"
- 打标工具：`原创保护千牛标打标` skill

## 签约状态流转

```
未签约 → 签约申请 → 审核中 → 签约成功 / 签约失败
签约成功 → 生效中 → 到期续签 / 解约
```

## 边界条件

1. 9 类白名单商家可自助签约（千牛端）
2. 非 9 类只能由运营在小二端手动签约
3. 签约后需等待审核，审核通过后生效
