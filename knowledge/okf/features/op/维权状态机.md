# OP 维权状态机

## 申请状态机（14 状态）

```
SAVING
  ├→ QUICK_AUDITING → QUICK_REJECTED (终态)
  │                  └→ PRE_PRE_AUDITING
  └→ PRE_PRE_AUDITING → PRE_REJECTED (终态)
                        └→ PRE_AUDITING → PRE_AUDITED → CERT_AUTHED → CERT_FILE_SYNCED
                                                                                  └→ YC_AUDITING → YC_AUDITED → PATENT_GRANTED (终态)
                                                                                               └→ YC_REJECTED (终态)
                                                                                                              └→ PATENT_REJECTED (终态)
```

## 状态说明

| 状态 | 含义 |
|------|------|
| SAVING | 草稿保存 |
| QUICK_AUDITING | 快审中 |
| QUICK_REJECTED | 快审驳回（终态） |
| PRE_PRE_AUDITING | 预审前置中 |
| PRE_REJECTED | 预审驳回（终态） |
| PRE_AUDITING | 预审中 |
| PRE_AUDITED | 预审通过 |
| CERT_AUTHED | 证书认证 |
| CERT_FILE_SYNCED | 证书文件同步 |
| YC_AUDITING | 原创保护审核中 |
| YC_AUDITED | 原创保护审核通过 |
| YC_REJECTED | 原创保护审核驳回（终态） |
| PATENT_GRANTED | 专利授权（终态） |
| PATENT_REJECTED | 专利驳回（终态） |

## 转普通触发条件

| 触发状态 | 是否触发转普通 |
|---------|-------------|
| PRE_REJECTED | ✅ 触发 |
| PRE_AUDIT_REJECT | ✅ 触发 |
| CERT_REJECT | ✅ 触发 |
| QUICK_REJECTED | ❌ 不触发 |

## 转普通状态流转

```
TO_DO → DONE（转普通完成）
TO_DO → TIMEOUT（超时未处理）
```
