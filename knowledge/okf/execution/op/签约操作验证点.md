# OP 签约操作验证点

## 千牛标检查

- **预期行为**: 无标商家进入服务页 → 显示提示信息
- **DOM 信号**: 页面包含文本 "抱歉，该服务现面向具备高原创能力要求的商家开放"
- **前置条件**: 使用无 TTYCBH 标的商家账号

## 签约状态断言

| 操作 | 预期结果 | 验证方式 |
|------|---------|---------|
| 提交签约申请 | 状态变为"审核中" | UI 状态标签 + DB 字段 |
| 审核通过 | 状态变为"签约成功" | UI 状态标签 + DB 字段 |
| 审核驳回 | 状态变为"签约失败" | UI 状态标签 |

## DB 层验证

```sql
-- 查询签约状态
SELECT seller_id, sign_status, gmt_create, gmt_modified
FROM yc_seller_sign
WHERE seller_id = <test_seller_id>
ORDER BY gmt_create DESC LIMIT 1;
```

## 数据构造前置

1. 商家账号必须有有效类目
2. 9 类白名单商家可走千牛端签约
3. 非 9 类只能小二端操作
