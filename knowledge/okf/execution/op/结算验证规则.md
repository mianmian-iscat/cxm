# OP 结算验证规则

## DB 表校验

```sql
-- 查询结算记录
SELECT right_id, settle_type, service_fee, subsidy_fee, status
FROM yc_right_settle_order
WHERE right_id = <test_right_id>;
```

## 金额计算公式验证

| 场景 | 预期公式 | 容差 |
|------|---------|------|
| 下架率 ≥ 70%（首发） | service_fee × 1.0 + subsidy | ±0.01 |
| 下架率 ≥ 70%（非首发） | service_fee × 1.0 | ±0.01 |
| 下架率 30-70%（首发） | service_fee × rate + subsidy | ±0.01 |
| 下架率 < 30%（首发） | subsidy_only | ±0.01 |
| 下架率 < 30%（非首发） | service_fee - subsidy - gov_fee | ±0.01 |

## 退款验证

```sql
-- 退款金额 = 剩余数量 × 500
SELECT refund_amount, remaining_count
FROM yc_right_settle_order
WHERE right_id = <test_right_id> AND settle_type = 'REFUND';
-- 验证: refund_amount == remaining_count * 500
```

- subsidy_first_test = 6
- subsidy_non_first_test = 4
