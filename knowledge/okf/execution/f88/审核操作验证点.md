# F88 审核操作验证点

## 9 按钮工具栏

审核详情页底部工具栏包含 9 个操作按钮：

| 按钮 | 可见条件 | 操作后状态 |
|------|---------|-----------|
| 通过 | 待审核状态 | 变为审核通过 |
| 驳回 | 待审核状态 | 弹出驳回原因弹窗 |
| 转交 | 待审核状态 | 弹出转交人员选择 |
| 撤回 | 待审核状态（管理员） | 变为已撤回 |
| 查看大图 | 始终可见 | 弹出图片预览 |
| 下载原图 | 始终可见 | 触发下载 |
| 编辑 | 文本类素材 | 打开编辑器 |
| 对比 | 有参考图时 | 打开对比视图 |
| 历史记录 | 始终可见 | 弹出历史面板 |

## 关键验证点

### 驳回必填校验

- **预期行为**: 点击驳回 → 弹窗 → 不填原因 → 确认按钮 disabled
- **DOM 信号**: 驳回原因 textarea 为空时，确认按钮 class 含 `ant-btn-disabled`
- **常见陷阱**: 不要直接点击确认，先验证按钮是否 disabled

### 通过确认

- **预期行为**: 点击通过 → 弹出二次确认 → 确认后状态变更
- **DOM 信号**: 确认弹窗出现后，状态标签文本变为"审核通过"

### 图片预览

- **预期行为**: 点击查看大图 → Modal 弹出 → 支持缩放/拖拽
- **DOM 信号**: `.ant-modal` 出现且包含 `<img>` 标签

## 数据构造前置条件

1. 必须先通过 API 创建审核任务（参见 [数据构造约束](数据构造约束.md)）
2. 任务状态必须为"待审核"才能执行审核操作
3. 租户身份头 `X-AFD-Emp-Identity` 必须正确设置
