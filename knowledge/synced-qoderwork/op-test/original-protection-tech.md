## 2. 核心业务流程

### 2.1 签约存证

- 白名单商家通过千牛标 `TTYCBH` 开放入口
- 入口路径：商品 → 商品运营 → 服饰原创保护
- 签约协议: https://terms.alicdn.com/legal-agreement/terms/b_end_product_protocol/20260116170412666/20260116170412666.html
- 签约后跳转存证页面: https://yc.alibaba.com/#/legalManage
- 签约白名单为原创内部逻辑，白名单内可成功签约

### 2.2 服务购买

- 定价: 500元/次（外观专利申请及维权服务包）
- 订购限制: 同一商家单自然月购买专利权益包不可超过100
- 额度永久有效，支持逆向交易（未使用次数可退）
- 退款规则: 退款金额必须为订单剩余金额的全部（500 × 剩余服务次数）

### 2.3 专利申请流程

#### 状态流转

```
草稿中 → 初审中(YC接单) → 专利权预审中(快维中心) → 外观设计专利权认证申请(国知局)
→ 专利保护中(授权成功) → 原创保护到期(转回/放弃)

各阶段可能分支：
- 待补充材料（初审/预审/国知局阶段均可触发）
- 初审驳回 / 预审驳回 / 国知局驳回
- 专利申请已终止（商家主动在补正节点终止）
- 转普通申请（驳回后可转普通国知局申请）
```

#### 关键状态枚举

| 状态 | 标签颜色 | 说明 |
|------|----------|------|
| 专利申请中 | 蓝色 | 从发起申请到授权成功前 |
| 专利保护中 | 绿色 | 授权成功到合作期内且未转回 |
| 专利已回转 | 绿色 | 已转回给商家 |
| 专利保护已失效 | 红色 | 合作到期，不再支持维权 |
| 专利申请已驳回 | 红色 | 初审/预审/国知局阶段被驳回 |
| 专利申请已终止 | 红色 | 商家自主在补正节点终止 |
| 草稿中 | 蓝色 | 四期新增，保存草稿不占用权益 |

#### 专利申请表单关键字段

- 设计人（必填，可多个）：姓名、国籍、身份证号码、身份证图片
- 联系人（必填，仅一个）：姓名、联系地址、邮编、手机、邮箱
- 产品名称（必填，20字内）
- 产品用途（必填，100字内）
- 产品所属类目（四期新增，必填，11个服饰类目枚举）
- 原创描述（必填，200字内）
- 设计要点（单选：A形状/B图案/C形状与图案结合/D形状与色彩结合/E图案与色彩结合/F色彩形状图案结合）
- 设计要点所属视图（多选：A立体图~G仰视图）
- 产品图片：主视图+立体图必传，支持10MB以内JPG/PNG
- 补充材料格式：jpg/jpeg/png/pdf/doc/docx/xls/xlsx/zip/rar/7z/tar/gz

#### 保护到期日计算规则（四期调整）

```
保护到期日 = min(商品确认一致性后180天, 专利申请日期+1自然年-30天)
```

保护到期日前20天限制：不允许发品（按钮置灰），不允许上报线索。
后端通过 diamond 配置控制时间参数。

### 2.4 商品绑定与发布

- 专利申请受理后可发布/绑定商品（v5改为收到YC回传申请编号+状态为"专利已受理"即可）
- 绑定商品弹窗两个tab：【未曾上架售卖】和【专利受理后上架】（首次上架时间晚于受理日期+1）
- 限制仅可管理1个商品且确认一致性后无法更换
- YC人工审核专利与商品一致性，不一致时解除关联关系
- 发布后商品信息按小时推送YC机构（ic标 4471490）

### 2.5 维权流程

- 巡检机制: 前3个月自动巡检（首月每周，后2个月每2周），3个月后商家主动提报
- 疑似侵权平台: 淘宝、天猫、抖音、小红书、拼多多、京东
- 累计销量: 预估商品从上架到识别侵权期间累计销量
- 到期前20天不可发起维权（按钮置灰）
- 维权状态: 维权成功已下架 / 维权中 / 维权失败
- 下架率目标: ≥70%（分子=180天内已下架线索，分母=商家发起维权且YC确认侵权的线索）

### 2.6 专利回转（保护到期操作）

操作时机：商品确认一致性后180天到申请日期+1年-30天期间

#### 放弃专利
- 二次确认后状态变为"专利保护已失效"
- 状态名称："原创保护到期，已放弃专利"

#### 申请专利转回
- 转回对象：本人 / 本店铺主体 / 其他（输入框100字内）
- 签署文件：转让协议、专利代理委托书、专利转让确认书（受让方非商家时）
- 需扣除"专利转回权益包"次数
- 状态名称："原创保护到期，专利回转中" → "专利已回转"

## 3. 结算系统

### 3.1 结算规则

| 业务场景 | 结算方式 | 周期 |
|----------|----------|------|
| 初审未通过/后续驳回/终止申请 | 系统触发退回500元到服务市场中间账户 | T+1, 日结 |
| 补贴后专利申请被驳回/终止 | 退回500-302/500-202，不返回服务次数 | T+1, 日结 |
| 合作服务到期（下架率≥70%） | 确收500-165，人工结算给供应商500-165 | 月结 |
| 合作服务到期（下架率<70%） | 扣款退回商家335-302/335-202（扣除75+90官费） | 月结 |
| 官费结算 | 月结: 授权案件数 × (75+90) | 月结 |
| 首发补贴（首发） | 从补贴账户退回商家302 | 商品首次上架日T+4 |
| 首发补贴（非首发） | 从补贴账户退回商家202 | 商品首次上架日T+4 |

### 3.2 结算状态机

#### 大状态机
```
[初始] → 进行中(提交专利申请)
进行中 → 已完成(合作到期 或 首发补贴后终止/驳回)
进行中 → 已取消(补贴前终止/驳回)
```
- 进行中和已完成占一个专利额度
- 已取消不占专利额度

#### 详细状态机
```
首发打标前 → 首发打标后 → 首发补贴中 → 首发已补贴 → [合作到期fork]
  ├→ 完结待退款(下架率不达标) → 完结退款中 → 完结已退款
  └→ 完结无需退款(下架率达标)

首发打标前 → [合作到期fork]（未补贴直接到期）
  ├→ 完结待确收(下架率达标)
  └→ 完结待退款(下架率不达标, 退款金额=500-165=335)

首发打标前/后 → 已取消(撤销/驳回)
首发补贴中/已补贴 → 完结待退款(撤销/驳回)
```

### 3.3 订购单 Pick 逻辑

1. 查询没有用于专利结算的订购单（没有状态为进行中和已完成的结算单）
2. 按交易时间正排
3. 计算余额 = 订单金额 - 商家退款中金额 - 商家已退款金额，余额须等于500

### 3.4 商家退款

- 可退金额 = 订购单金额 - 关联进行中和已完成结算单数×500 - 商家退款中金额 - 商家已退金额
- 退款提交前校验：退款金额必须等于订购单剩余可退金额
- 退款策略: `fwportal_refund_confirm`

### 3.5 开票冻结/解冻

- BY月洗冻结&解冻表给账房
- 账房开票表: `seller_fin_data.s_hj_fin_invoice_evaluate_taobao_invoice_output_app`

## 5. 技术模块详情

### 5.1 取消专利申请

YC在内审/初审/国知局阶段可取消申请专利，取消后商家权益+1。
- 已终止/已驳回/已下发证书状态不能取消
- 四期新增：初审通过前显示"取消申请"按钮，取消后返回服务次数
- 草稿状态不占用权益

### 5.2 驳回&终止恢复服务次数

- 内审驳回: 恢复1次
- 预审驳回: 恢复1次
- 国知局驳回: 恢复1次
- 国知局补充材料时商家终止申请: 恢复1次

### 5.3 承诺书电子用印

- 每次专利申请时提供【北京快维中心承诺书】（仅淘宝主体公章PDF）
- 接口: 文档渲染 `DocumentService`，创建渲染实例 `TemplateInstanceGroupService#createTemplateInstanceGroup`
- 模板中心日常: https://openei.alibaba.net/open_plat_form/applySubmit_v2?appCode=template-center-core
- 合同中心（双方盖章）: https://openei.alibaba-inc.com/open_plat_form/docCenter_v2?bookCode=antis-saas

### 5.4 去除绿网校验

- 山海关环境下上传敏感信息不调用绿网接口
- 添加线索、白名单去掉绿网校验
- 预发环境测试账号: 八载02

### 5.5 商品详情页展示

各状态下商详专利模块展示逻辑:
- 专利申请中: 展示受理编号
- 专利已成功: 展示专利号
- 审核不一致: 展示提示
- 终止申请/驳回: 不展示或展示特定状态

### 5.6 可关联商品逻辑迭代

绑定商品弹窗:
- 【未曾上架售卖】tab: 从未上架过的商品
- 【专利受理后上架】tab: 首次上架时间晚于受理日期+1的商品（含受理日期当天首次上架）

### 5.7 白名单URL及首发打标规则

- 必须有商品确认一致性时间才能编辑"是否首发"标签
- 取min(首次上架时间, 确认一致性时间) + T+3天内可编辑，第4天0点后不可修改
- 白名单URL自动加入: 购买成功后获取本店铺链接自动加入
- 所属平台枚举: 淘宝、天猫、抖音、小红书、拼多多、京东

### 5.8 转普通申请

**业务背景**: "存在相似款"(49.2%)和"不够新颖"(33.9%)是两大核心驳回原因，合计83.1%。预计可挽回18%左右专利申请。

**流程**:
1. YC操作转普通申请（初审驳回/预审驳回后可操作）
2. 更新 `to_regular_status` = `TODO`，记录建议时间和原因
3. 商家端展示"提交普通申请"按钮（仅 `toRegularStatus=TODO` 时）
4. 商家点击二次确认弹窗 → 扣除服务次数 → `to_regular_status` = `DONE`
5. 状态流转: 初审驳回→初审中 / 预审驳回→初审通过
6. 超时: 每天2:00扫描，`to_regular_suggest_time < (当天0点-2天)` → `TIMEOUT`

**接口**: `taobao.industry.yc.right.apply.get` 返回 `toRegularStatus`, `suggestToRegularReason`, `regularApply`

**运营限制**: `to_regular_status` 不为空时不可编辑"是否首发"字段

## 6. 淘内首发保护

### 6.2 淘内首发TAB状态

| 平台原创保护已失效 | 审核状态=EXPIRED过期 |

### 6.3 AI图首发保护入口

商品发布流程新增AI图首发保护入口:
- 白名单控制展示
- 服务授权弹窗（协议签署）
- 图片选择弹窗（初审过滤规则: 尺寸≥700px、含水印/ID、有生成/拍摄历史、未曾发布/申请过）
- 提交完成弹窗
- 商品列表页状态查询入口

### 6.4 首发保护二期优化

数据: 23家签约商家，19992张图片处理，94.97%备案通过率。
4个核心问题:
1. PS编辑后水印识别失败（93.34%的失败原因）
2. 跨店水印不匹配
3. 初审到提交转化率低（仅35%）
4. 结果查询路径问题
