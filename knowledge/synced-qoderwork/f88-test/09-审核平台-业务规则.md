# F88 平台业务规则

## 审核功能规则

### 审核标题与内容
- 审核标题统一为"首图审核"
- 操作按钮为"确认"和"丢弃"（非"通过"/"不通过"）
- Prompt 限制为 2000 字符（PRD规范，UI显示3000为前端实现偏差）

### 图片上传
- 图片上传非必填
- 仅支持 png/jpg/jpeg 格式
- 其他格式应给出明确错误提示

### 审核状态流转
- 待审核 → 已确认 / 已丢弃
- 已丢弃 → 支持"重新审核"
- 已确认 → 终态，不可重新审核

### 已知额外UI元素
UI 存在 PRD 未提及的额外按钮：
- 裁剪
- 高清化
- redo（重做）
- 驳回

### 图片编辑确认流程（所有编辑操作通用规则）
- **核心规则**：局部修改（布局修改）、替换、高清化——所有图片编辑操作完成后，必须点击「编辑后」tab + ✅确认，底部工具栏（copyURL、下载、替换、裁剪、高清化、负反馈、复位等）才会出现
- **未确认时的行为**：
  - 底部工具栏不可见，无法使用copyURL、下载等任何操作按钮
  - 修改结果仅存储在临时状态中（如局部修改存在 `extra.localAdjustResultList` 的 `localAdjustUrl`）
  - `url` 和 `originUrl` 均不更新，仍指向原始图片
- **确认后的行为**：
  - 底部工具栏出现，可使用所有操作按钮
  - `url` 字段更新为编辑后的URL（如 `localAdjustUrl`）
  - `originUrl` 保持为原始URL（不变）
  - `localAdjustStatus` 重置为0（局部修改场景）
  - copyURL返回正确的编辑后URL
- **测试要点**：
  - 验证任何编辑操作的效果时，必须先完成「编辑后+✅确认」步骤，否则工具栏不可见、无法测试
  - 跳过确认步骤会误判为功能缺陷，实际是设计行为——未确认的编辑不算生效
  - 此规则适用于所有审核类型（首图qt=4、套图qt=2）的所有编辑操作

## 抽检功能规则

### 抽检任务
- 抽检任务URL: `/review/personal-task-center?ptcTab=spotCheck`
- 视频抽检详情页: `/review/task/detail?taskId={id}&taskType=spotCheck`

### 抽检指标
- **passRate（审核通过率）**：审核通过的比率
- **accuracyRate（抽检正确率）**：抽检结果与审核结果一致的比率
- 两个指标独立计算

### 抽检状态码
| 状态码 | 含义 |
|--------|------|
| 1 | 已完成 |
| 2 | 待抽检 |
| 0 | 重置后待审核 |

### 视频抽检"不通过"
- 实际UI为驳回弹窗
- 驳回原因选项：测试原因1 / 测试原因2 / 测恶女 / 手动输入
- 操作按钮为"确认驳回"
- 非测试文档预期的"确认/丢弃"按钮

## 策略平台规则

### LLM节点视频理解
- 支持视频理解的模型（2个）：gemini-3-flash-preview、gemini-3.5-flash
- gemini-2.5-flash-0617 已移除，不再支持视频输入
- 视频输入上限：10条（后端 MAX_VIDEO_INPUT_COUNT=10）
- 前端输入上限：15项（图片+视频混合，MAX_IMAGES=15），前后端上限不一致
- 支持的视频格式：.mp4/.avi/.mov/.mkv/.webm/.flv/.wmv
- Gemini 模型走 NanoBanana(Vertex API) 路径，使用 fileData 格式
- Qwen 模型走 OpenAI 兼容接口，视频以 video_url 类型传入
- Claude 模型不支持视频输入

### 批次生命周期
1. 批次创建 → 各环节按顺序执行
2. 环节顺序：设计改款 → 视觉生图 → 视觉审核 → 算法过滤 → 套图生产 → 选款推送
3. 每个环节完成后触发下一个环节

### 节点重试
- 失败节点支持手动重试
- 重试不影响已完成的其他节点
- LLM资源不足时，重试可能再次失败

## 素材生产规则

### 两种入口类型
| 类型 | source_type | 触发方式 | batch_name模式 |
|------|-------------|---------|---------------|
| 从无到有 | F88 | 每日20:00自动 | F88商品主图生成_{YYYYMMDDHHmm} |
| 主动提报 | F88_MATERIAL | 小二手动创建 | F88素材生成_{date} 或 F88素材生成_{linkId}_{MMDD_HHMM} |

### 三种处理模式（主动提报专属）
- **replacePic**（换图）：替换现有商品图，成功率~51%
- **seedGenerate**（种子图生成）：生成种子图，成功率~77%
- **generateMaterial**（完整素材生成）：完整素材生产，成功率~23%

### 操作安全红线 ⚠️
**只有供给品标题含「测试请不要拍」的数据才可操作（推送/创建任务/AI预审复核），其他均为生产数据只读。**
- 测试seller：2219662018344 / 2219635649153
- 从无到有链路：input_data 无 f88_stage / process_mode
- 主动提报链路：input_data 含 f88_stage="supplyItemPreAudit" + process_mode

## 数据库说明

### 核心表
- **workflow_record_log**：节点执行记录
- **g_workflow_instance**：工作流实例

### 查询优化要点
- `node_type` 字段无索引，需加 `id > 4000000` 范围条件
- `seller_id` 通过 `JSON_EXTRACT(common_variable, '$.seller_id')` 提取
- `strategyName` 通过 `JSON_EXTRACT(extra_info, '$.strategyName')` 提取
- 避免使用 `JSON_VALID()` 函数
- ORDER BY 必须带 LIMIT（ODPS限制）

### 搭配推荐商品表
- 表名：`taobao_tec_platform.afd_shop_template_flat`
- 用途：搭配推荐系统的商品特征宽表（25列）
- 15个匹配维度已预提取为独立字段：
  - item_category, item_style, item_season, item_age_group
  - main_color_hue, main_color_saturation, main_color_brightness
  - pattern_content, dress_length, skirt_length, pants_length
  - sleeve_length, coat_fitting, pants_fitting, skirt_fitting
- 每条记录是一个单品模版（image_url级别），非整套搭配
