# F88 视频生产（视频生成+推送节点）

## 视频生成处理器（`GenVideoProcessor`）

| NodeType | 处理器 | 处理类型 | 核心逻辑 |
|----------|--------|----------|----------|
| `gen_video` | `GenVideoProcessor` | AI 生视频 | 千牛视频 SDK（`QN_VIDEO_SDK`），最多 3 张输入图，非 alicdn 图自动上传，返回视频 URL + 封面 URL |

- **支持重试**：✅
- **支持重产**：—
- **环节类型**：`VIDEO`（视频）

### 视频生成流程

```
1. 解析输入（最多 3 张图片）
2. 非 alicdn 图片自动上传到 CDN
3. 调用千牛视频 SDK（QN_VIDEO_SDK）生成视频
4. 返回视频 URL + 封面 URL
5. 创建素材记录
6. 发送 WorkflowRecordFinishMessage
```

## 视频理解限制

- **支持模型**：gemini-3-flash-preview、gemini-3.5-flash（gemini-2.5-flash-0617 已移除）
- **视频上限**：10 条（后端 `MAX_VIDEO_INPUT_COUNT=10`）
- **前端上限**：15 项（图片+视频混合，`MAX_IMAGES=15`），前后端上限不一致
- **支持格式**：.mp4 / .avi / .mov / .mkv / .webm / .flv / .wmv

**QA 风险点**：前后端视频上限不一致——后端 10 条 vs 前端 15 项。

## 视频相关失败排查

| 错误特征 | 类别 | 处置 |
|----------|------|------|
| `Cannot fetch content` | URL 不可访问 | 检查图片/视频 URL 有效性 |
| `429` / `RESOURCE_EXHAUSTED` | Quota 耗尽 | 手动重试（`workflow_fail_retry`） |
| `500` / `Internal error` | 模型内部错误 | 少量可接受，大量需上报 |

## 视频 URL 格式与来源

F88 视频 URL 有两种来源，格式和处理方式不同：

| 来源 | URL 格式 | 签名 | 时效性 | `isVideoUrl()` 兼容性 |
|------|---------|------|--------|----------------------|
| scene-ossgw.taobao.com | `https://scene-ossgw.taobao.com/costume_project/resource/sd/seedance_video_{id}_{ts}.mp4` | 无签名 | 长期有效 | 正常（以 `.mp4` 结尾） |
| OSS 签名 URL | `https://{bucket}.oss-cn-{region}.aliyuncs.com/{path}?Expires={ts}&OSSAccessKeyId={key}&Signature={sig}` | 有签名 | Expires 过期后 403 | **失败**（不以 `.mp4` 结尾） |

**`isVideoUrl()` 缺陷**：`endsWith(".mp4")` 判断方式对 OSS 签名 URL 失效，导致视频被误判为非视频，推送时静默丢弃。详见 `patterns/video-push-code-defects.md`。

## 视频输出物校验（ffprobe）

gen_video 成功后，用 ffprobe 验证输出视频参数是否符合策略配置：

| 参数 | 校验方式 | 典型值 |
|------|---------|--------|
| 分辨率 | `ffprobe -select_streams v:0 -show_entries stream=width,height` | 1248x1664（竖屏 3:4） |
| 编码 | `ffprobe -select_streams v:0 -show_entries stream=codec_name` | h264 / hevc |
| 帧率 | `ffprobe -select_streams v:0 -show_entries stream=r_frame_rate` | 24/1 / 25/1 / 30/1 |
| 时长 | `ffprobe -show_entries format=duration` | ≤ 60s |
| 完整性 | `ffprobe -v error {file}` | 无输出 = 文件完整 |

**安装**：`pip3 install --user static-ffmpeg`（symlink 在 `~/.local/bin/`，无需 Homebrew）。

**校验流程**：DB 取 `output_json.$.outputVideo` → curl 下载 → ffprobe 提取参数 → 对比 `g_strategy.workflow_def` 中 gen_video 节点的 `imageSize` / `outputRatio`。

详细基础设施见 [infra/ffmpeg-verification.md](../infra/ffmpeg-verification.md)。
