# 测试用例完整性检查清单

## 功能维度检查

### 核心业务流程
- [ ] 主流程（Happy Path）完整覆盖
- [ ] 所有分支路径有对应用例
- [ ] 流程中断和恢复场景

### 数据操作（CRUD）
- [ ] 创建：正常创建 + 重复创建 + 批量创建
- [ ] 读取：列表查询 + 详情查询 + 分页 + 排序 + 筛选
- [ ] 更新：全量更新 + 部分更新 + 并发更新
- [ ] 删除：单条删除 + 批量删除 + 级联删除 + 软删除验证

### 接口参数
- [ ] 必填参数缺失
- [ ] 可选参数缺失组合
- [ ] 参数类型错误（字符串传数字等）
- [ ] 参数边界值（最大/最小/空/超长）
- [ ] 特殊字符和注入尝试

### 状态流转
- [ ] 所有合法状态转换路径
- [ ] 非法状态转换被拒绝
- [ ] 并发状态冲突
- [ ] 状态回退/重置

## 非功能维度检查

### 权限控制
- [ ] 未登录访问
- [ ] 无权限角色访问
- [ ] 跨租户/跨项目访问
- [ ] 数据权限（只能看到自己的数据）

### 性能
- [ ] 大数据量场景（万级/十万级）
- [ ] 并发访问
- [ ] 响应时间基准

### 兼容性
- [ ] 多浏览器（Chrome/Firefox/Safari/Edge）
- [ ] 移动端适配
- [ ] 不同分辨率

### 异常场景
- [ ] 网络中断/超时
- [ ] 重复提交
- [ ] 服务降级
- [ ] 数据库连接失败

## F88/i-FASHION 特有检查项

### 审核相关
- [ ] 审核标题、内容、图片的组合校验
- [ ] Prompt字符限制（2000字符）
- [ ] 图片格式限制（png/jpg/jpeg）
- [ ] 审核状态完整流转
- [ ] 已丢弃重新审核

### 抽检相关
- [ ] 抽检任务创建和分配
- [ ] 通过率和正确率独立计算
- [ ] 视频抽检驳回流程
- [ ] 抽检结果统计

### 策略平台
- [ ] 批次创建参数校验
- [ ] 各环节状态检查
- [ ] 节点重试机制
- [ ] 失败恢复流程
