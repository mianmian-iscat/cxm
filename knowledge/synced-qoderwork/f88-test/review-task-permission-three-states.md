# 审核平台任务状态三档权限控制

## 概述

审核平台编辑抽屉的权限按任务状态分为三档控制，决定哪些字段可编辑、哪些被锁定。这是审核任务管理的核心权限模型，涉及前端（辰承）和服务端（俨冰）两端改动。

## 详细内容

### 三档权限模型

| 任务状态 | 可编辑范围 | 锁定范围 |
|----------|-----------|----------|
| **待开始** | 全部字段可编辑 | 无 |
| **进行中** | 检查设置可编辑 | 任务分配锁定 |
| **已完成** | 无 | 全部锁定 |

### 实现细节

- **前端**: 辰承负责，根据任务状态动态控制编辑抽屉的字段可编辑性
- **服务端**: 俨冰负责，API层校验权限，防止绕过前端直接调用
- **关联需求**: 81007712（编辑任务重新分配）

### 测试要点

1. 三种状态下分别验证编辑抽屉的字段可用性
2. 进行中状态下的"任务分配锁定"是否生效（尝试修改分配人）
3. 已完成状态下是否所有字段都不可编辑
4. API层权限校验是否与前端一致（绕过前端直接调用API）

## 验证方法

1. 创建三种状态的审核任务
2. 分别打开编辑抽屉，检查各字段的可编辑性
3. 尝试通过API直接修改，验证服务端校验
