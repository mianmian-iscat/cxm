# F88 流式启动（SchedulerX+队列水位控制）

> **来源**：前端 `industry-source-code/iFashion-tools` + 后端 `stylespot/stylespot-admin`
> **底层应用**：cloth-btgplatform (appId: 251680)

> ⚠️ **操作安全红线**：供给品标题必须含「测试请不要拍」才可执行写操作（推送/创建任务/AI预审复核/发起素材生产）。其他均为生产数据，只读禁止写。测试seller: 2219662018344 / 2219635649153。

## 系统架构概览

### 三层架构

```
前端 (iFashion-tools, React + Redux + Axios)
  │  REST API (/api/workflow2/*, /api/workflow/batch/*, /api/afd/*)
  ▼
后端 (stylespot-admin, Pandora Boot + Spring Boot 2.5.12 + Java 11 + MyBatis Plus)
  │  DDD 分层: common → client → domain → infrastructure → application → interfaces → start
  ▼
数据层 (MySQL: stylespot@rm-lgay0v5lor8396yka, Tair 缓存, MetaQ 消息, Diamond 配置)
```

### 生产流水线三级模型

```
批次 (Batch, BT_xxxx)
  └─ 环节 (Stage) — 按顺序流转，如 设计改款 → 视觉生图 → 视觉审核 → 算法过滤 → 套图生产 → 选款推送
       └─ 节点 (Node) — 环节内并行执行的任务单元（策略→具体处理节点）
```

**节点状态流转**：`INIT → TO_SUBMIT → HANDLING → SUCCESS / FAIL`（审核节点额外有 `RETRYING`、`PERM_FAIL`）

**批次状态**：`INIT → SUBMITTED → PROCESSING → FINISHED / TERMINATED`

## 工作流引擎核心流程

### 引擎接口：`Workflow2Engine`

| 方法 | 作用 |
|------|------|
| `submitWithStrategy()` | 从策略创建 workflow instance + 首节点 record |
| `submitWithNode()` | 从单节点创建 instance |
| `submitWithLink()` | 从链路创建 instance，委托 `submitWithStage()` |
| `submitWithStage()` | 策略匹配逻辑：① input 中 `target_strategy_id` ② 商家运营策略匹配 ③ 默认策略兜底 |
| `startBatch()` | 启动批次所有 INIT 状态的首节点 record |
| `startSomeRecord()` | 调度器驱动：跨所有 PROCESSING 批次批量启动 INIT record（限流 count=100） |
| `onNodeStart()` | 节点执行：变量解析 → 分布式锁 → 种子素材生成 → `NodeProcessor.process()` |
| `onNodeFinish()` | 节点完成：更新状态 → 查找下游节点 → 创建后续 record（支持裂变） |

## 定时任务

| 任务 | 路径 | 作用 |
|------|------|------|
| `Workflow2RecordStartJob` | `.../scheduler/Workflow2RecordStartJob.java` | **核心调度器**：遍历所有租户，调用 `startSomeRecord(tenantId, 100)` 批量启动 INIT record。排除 APPROVE 节点（单独处理）。Tair 标记防重 |
| `WorkflowBatchProgressJob` | `.../scheduler/WorkflowBatchProgressJob.java` | 找近期修改批次 → `statisticProgress()` 更新进度统计 |
| `ApproveTaskGenProgressJob` | `.../scheduler/ApproveTaskGenProgressJob.java` | 扫描审核触发 → `tryPushApproveTask()` 生成审核任务 |
| `BatchAsyncSubmitJob` | `.../scheduler/BatchAsyncSubmitJob.java` | 异步批次提交处理 |
| `BatchAutoFinishProcessor` | `.../scheduler/BatchAutoFinishProcessor.java` | 自动完成已完成批次 |
| `AfdMaterialConvertProcessor` | `.../scheduler/AfdMaterialConvertProcessor.java` | 素材转换 |
| `AfdCaptionOutputRefreshJob` | `.../scheduler/AfdCaptionOutputRefreshJob.java` | Caption 输出刷新 |

## 前端技术栈

### 架构

- **框架**：React + Redux
- **HTTP**：Axios（全局请求拦截器注入 `X-AFD-Emp-Identity` 头）
- **多租户**：Redux store 的 `tenant.currentIdentity` 控制租户身份
- **CDN**：`https://dev.g.alicdn.com/industry-source-code/iFashion-tools/{version}/js/index.js`

### 租户切换机制

```
切换租户 → cacheEmployeeIdentity() + queryTenantMenu()
         → Axios interceptor 自动注入 X-AFD-Emp-Identity 到后续所有请求
```

**QA 风险点**：新开 tab 时务必确认当前身份为 F88，否则可能串租户（如串到 AFD）。
