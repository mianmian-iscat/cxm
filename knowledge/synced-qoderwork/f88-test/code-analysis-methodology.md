# 代码分析方法论

## 分支覆盖策略

### 条件分支（if/else）
- 每个条件至少两个用例：条件为真 + 条件为假
- 嵌套条件：分析所有路径组合，但只覆盖业务有意义的路径
- 短路求值：关注 &&/|| 的前后顺序对结果的影响

### Switch/Match 分支
- 每个 case 一个用例
- default/fallback 分支必须有覆盖
- 枚举类型：验证未定义的枚举值处理

### 三元表达式
- 条件为真和为假各一个用例

## 异常处理分析

### 常见异常类型及测试策略
| 异常类型 | 触发方式 | 验证要点 |
|---------|---------|---------|
| 参数校验异常 | 传入非法参数 | 错误码和提示信息准确 |
| 业务逻辑异常 | 触发业务规则限制 | 异常被正确抛出和捕获 |
| 数据库异常 | 唯一约束/外键/超时 | 事务回滚、数据一致性 |
| 网络超时异常 | 外部服务延迟 | 超时配置、重试策略、降级逻辑 |
| 并发冲突异常 | 同时操作同一资源 | 锁机制、幂等性 |
| NPE/空指针 | 未判空的引用访问 | 空值防御是否完善 |

## 接口测试用例模板

### 正向用例
```
接口: POST /api/v1/resource
场景: 正常创建资源
请求体: 完整有效参数
预期: 200 + 资源ID返回 + DB数据一致
```

### 参数校验用例

## 数据库测试关注点

### 字段约束
- NOT NULL 字段是否可能写入 NULL
- UNIQUE 约束的冲突处理
- 字段长度限制（VARCHAR长度）
- 枚举字段写入非法值

### 索引有效性
- 查询条件是否命中索引
- 大数据量下的查询性能
- 联合索引的最左前缀原则

### 事务一致性
- 部分失败时事务是否正确回滚
- 并发事务的隔离级别影响
- 长事务的超时处理
