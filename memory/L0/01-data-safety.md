# 铁律 1: 禁止删除历史存量数据

> **级别**: 红线 | **违反后果**: 不可恢复的数据丢失

## 规则

任何测试脚本、自动化流程、Agent 操作都**禁止**删除历史存量数据。

## 适用范围

- F88 策略/审核任务/素材记录
- 原创保护 权利申请/结算记录/维权记录
- AFD 迭代/Brief/试拍数据
- 所有其他业务域的历史数据

## 正确做法

| 场景 | 正确做法 | 错误做法 |
|------|---------|---------|
| 需要新测试数据 | 通过 API 创建新数据 | 复用/修改已有数据 |
| 测试完成后 | 标记为测试数据（不删除） | 清理/删除数据 |
| 必须清理 | 只清理本次会话创建的（按时间戳识别） | 删除所有匹配数据 |
| DB 操作 | 只 INSERT/UPDATE | 禁止 DELETE（除非明确是本次数据） |

## 识别测试数据

- 名称/标题包含 `[TEST]` 或 `[自动化]` 前缀
- 创建时间在测试会话时间范围内
- 通过 `gmt_create` 字段判断
