# 铁律 3: 测试会话不强制上报 att-tf

> **级别**: 用户偏好 | **违反后果**: 不必要的流程开销

## 规则

用户在 web-automation 项目中执行测试时，**不需要**强制走 att-tf 上报流程。

## 默认行为

| 用户说 | 行为 |
|--------|------|
| "测一下" / "验证" / "跑用例" | 直接测试，结果存 artifacts/ |
| "测完上报" / "同步 testflow" | 走 att-tf 上报流程 |
| 未明确 | 默认不上报 |

## 结果保存

测试执行结果通过以下方式保存：

- `artifacts/` 目录的 JSON 文件
- 截图文件（PNG/JPG）
- 测试报告（Markdown）

## 何时上报

只有以下情况才调用 att-start/att-report：

1. 用户明确说"上报"、"同步 testflow"
2. 用户明确说"这次要走 att-tf"
3. 需求关联了 Aone 工作项且用户要求上报
