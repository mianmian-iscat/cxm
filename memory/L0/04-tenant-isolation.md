# 铁律 4: 数据安全与租户隔离

> **级别**: 安全红线 | **违反后果**: 跨租户数据污染

## 规则

F88 和 AFD 平台通过 `X-AFD-Emp-Identity` 请求头进行租户隔离。操作前必须确认当前租户身份。

## 租户标识

| 身份 | 请求头值 | 可见数据 |
|------|---------|---------|
| F88 | `X-AFD-Emp-Identity: f88` | F88 策略/审核/素材 |
| AFD | `X-AFD-Emp-Identity: afd` | AFD 迭代/Brief/店铺 |

## 操作前检查

每次操作前确认：

1. 当前请求头设置正确
2. 操作的数据属于当前租户
3. 不会意外操作其他租户的数据

## 陷阱

- 切换租户后，前一个租户的数据**不可见**（不是删除，是隔离）
- 同一浏览器会话中切换租户，需要刷新页面
- API 调用时忘记设置租户头，默认可能走 F88
