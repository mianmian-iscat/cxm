# L1 上下文 — 原创保护平台

> 当前活跃的 OP 项目上下文。执行 OP 相关测试时加载。

## 当前测试范围

- 签约入驻（9 类/非 9 类/千牛标）
- 结算管理（效果对赌、补贴触发、退款）
- 维权保护（线索、巡检、提交维权）
- 首发标签（编辑权限、保护期、禁发期）

- 结算公式精度容差 ±0.01
- 补贴时序：必须先设开始时间再设到期时间
- 千牛标打标后才能进入签约页面
