### 铁律 3: 测试会话不强制上报 att-tf

- **文件**: [L0/03-no-att-report.md](L0/03-no-att-report.md)
- **摘要**: 除非用户明确要求，否则不走 att-tf 上报流程

### 铁律 4: 数据安全与租户隔离

- **文件**: [L0/04-tenant-isolation.md](L0/04-tenant-isolation.md)
